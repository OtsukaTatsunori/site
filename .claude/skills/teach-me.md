# teach-me

初学者モードを明示的にONにするスキル。

## 前提

通常時も `CLAUDE.md` のルールで初学者向けの丁寧な回答を心がけているが、このスキルを呼ばれたら**それをさらに強化**する：

## 強化されるルール

1. **すべてのコマンドにコメントを添える**
   ```powershell
   cd C:\Users\t1528\Documents\site\site   # リポジトリに移動
   git pull origin claude/enable-cocoon-child-cd2DT   # 最新版を取得
   ```

2. **何が起こるか事前に説明する**
   - 「このコマンドを実行すると、リモートの最新コードをローカルに取り込みます」
   - 「画像が6枚生成されて、articles/images/ フォルダに保存されます」

3. **エラーパターンを先回りで示す**
   - 「もし `command not found` と出たら、Pythonがインストールされていません」
   - 「もし `403 Forbidden` と出たら、WAFをOFFにしてください」

4. **用語は初出時に解説する**
   - `git pull`: リモートの最新変更をローカルに取り込むコマンド
   - `push`: ローカルの変更をリモートに送ること
   - `stash`: 未コミットの変更を一時退避すること

5. **ファイルの開き方・見方を具体的に書く**
   - 「`start ファイル名.png` でデフォルトアプリで開きます」
   - 「エクスプローラーのアドレスバーをクリックするとパスが表示されます」

6. **確認ポイントを示す**
   - コマンド実行後に「✅ こういう結果が出たら成功です」と示す
   - 失敗例も併記：「❌ 404エラーが出たら、URLを見直してください」

## 解除

ユーザーが「通常モードでOK」「もう慣れた」等と言ったら、通常のCLAUDE.md準拠に戻す。
