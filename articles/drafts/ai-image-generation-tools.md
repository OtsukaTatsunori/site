## 各ツールの詳細

### 1. Midjourney — 最高画質の代名詞

| 項目 | 内容 |
|---|---|
| 料金 | Basic $10/月 / Standard $30/月 |
| 操作方法 | Discordまたは公式サイト |
| 得意分野 | アート、イラスト、写真風、コンセプトアート |
| 商用利用 | 有料プランのみOK |

**向いている人**：最高品質の画像を作りたいクリエイター。

**強み**：画質・美しさがトップクラス。独自のアートスタイルが魅力。

**弱み**：無料枠なし。Discord操作が初心者にはやや難しい。

> 💬 **現場の本音**：Midjourneyは「プロンプトを工夫する楽しさ」がある反面、思い通りの画像が出るまで何度も試行錯誤が必要です。最初の1週間は練習と割り切ってください。

### 2. DALL-E（ChatGPT内蔵） — 最も手軽

| 項目 | 内容 |
|---|---|
| 料金 | ChatGPT Plus（月約3,000円）に含まれる |
| 操作方法 | ChatGPTの画面でテキスト入力 |
| 得意分野 | 説明的な画像、ビジネス用途 |
| 商用利用 | OK |

**向いている人**：ChatGPTをすでに使っている人。手軽に画像を生成したい人。

**強み**：日本語プロンプトの精度が高い。ChatGPTと同じ画面で使える手軽さ。

**弱み**：アーティスティックな表現ではMidjourneyに劣る。

### 3. Stable Diffusion — 無料＆カスタマイズ自由

| 項目 | 内容 |
|---|---|
| 料金 | 無料（ローカル実行） / オンライン版もあり |
| 操作方法 | ローカルPCにインストール or WebUI |
| 得意分野 | あらゆるスタイル（モデル次第） |
| 商用利用 | OK |

**向いている人**：細かいカスタマイズがしたい人。GPUを搭載したPCがある人。

**強み**：完全無料。モデル（LoRA等）を追加して画風を自由にカスタマイズ可能。

**弱み**：セットアップにPC知識が必要。高性能GPU（VRAM 8GB以上）推奨。

### 4. Adobe Firefly — 著作権が最も安全

| 項目 | 内容 |
|---|---|
| 料金 | 無料枠あり / Creative Cloud（月約7,000円）に含まれる |
| 操作方法 | ブラウザ or Photoshop内 |
| 得意分野 | 写真編集、広告素材、ビジネス用途 |
| 商用利用 | ◎（Adobe Stock学習で著作権リスク最小） |

**向いている人**：商用利用の著作権リスクを避けたい人。Adobe CCユーザー。

**強み**：Adobe Stockの素材で学習しているため、**商用利用時の著作権リスクが最も低い**。

**弱み**：アート系の表現力はMidjourney・Stable Diffusionに劣る。

### 5. Canva AI — デザイン初心者の味方

| 項目 | 内容 |
|---|---|
| 料金 | 無料枠あり / Pro月1,500円 |
| 操作方法 | ブラウザ（Canvaのデザイン画面内） |
| 得意分野 | SNS投稿、プレゼン資料、サムネイル |
| 商用利用 | OK |

**向いている人**：デザイン未経験。SNS投稿やプレゼン資料に画像を使いたい人。

**強み**：テンプレートと組み合わせてすぐ完成品が作れる。操作が最も簡単。

> 💡 **初心者へのアドバイス**：「どれを選べばいいかわからない」なら、まず**Canva AI**で始めてください。無料でテンプレートもあるので、5分で最初の画像が作れます。物足りなくなったらMidjourneyに進むのがスムーズです。

### 6. Leonardo AI — 無料枠が最も充実

| 項目 | 内容 |
|---|---|
| 料金 | 無料（1日150トークン ※約30〜50枚） / Pro $12/月 |
| 操作方法 | ブラウザ |
| 得意分野 | ゲーム素材、キャラクター、コンセプトアート |
| 商用利用 | OK |

**向いている人**：まず無料でたくさん試したい人。ゲーム・キャラ系が得意。

**強み**：無料枠が圧倒的に多い（1日150トークン（約30〜50枚相当））。初期投資ゼロで始められる。

## 著作権の注意点

| ポイント | 詳細 |
|---|---|
| **各ツールの規約を確認** | 商用利用の可否・条件はツールごとに異なる |
| **実在の人物の生成は避ける** | 肖像権・パブリシティ権の侵害リスク |
| **既存の作品のコピーは避ける** | 特定のアーティスト名をプロンプトに入れて類似作品を生成することは著作権侵害のリスクがある |
| **クライアントに事前説明** | AI生成であることを伝えるべきケースがある |

> ⚠️ **重要**：AI画像生成の著作権は2026年現在も法的に不透明な部分があります。商用利用する場合は、**著作権リスクが最も低いAdobe Firefly**を選ぶか、利用規約を必ず確認してください。

## よくある質問

### Q. 完全無料で使えるツールは？

Leonardo AI（1日150トークン（約30〜50枚相当））とStable Diffusion（ローカル実行）が完全無料です。CanvaとAdobe Fireflyにも無料枠があります。

### Q. 日本語のプロンプトで使える？

DALL-E（ChatGPT）とCanva AIは日本語に強いです。Midjourneyは英語が推奨。ChatGPTに「英語の画像生成プロンプトに変換して」と頼む方法もあります。

### Q. スマホでも使える？

DALL-E（ChatGPTアプリ内）、Canva AI、Leonardo AIはスマホ対応です。
