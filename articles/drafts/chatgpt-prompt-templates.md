ChatGPTは**プロンプト（指示文）の書き方**で回答の質が10倍変わります。

この記事では、仕事ですぐ使える**コピペ可能なプロンプト30選**をカテゴリ別に紹介します。自分の仕事に合わせてカスタマイズしてください。ChatGPTを使った[仕事効率化の全体像](/ai-work-efficiency/)もあわせてご覧ください。

> 💬 **現場の本音**：プロンプトは「完璧な1回」を目指すのではなく、「70点の下書き → 修正指示で仕上げる」のが現実的です。ChatGPTとの対話は**キャッチボール**。1往復で完成させようとしないでください。

**この記事でわかること：**
- 仕事で即使えるプロンプト30選（コピペ可能）
- メール・Excel・企画書・翻訳など6カテゴリ別
- うまくいかないときの修正指示の出し方

## プロンプトの基本ルール

![ChatGPTプロンプトの5つの基本ルール](UPLOAD_URL:chatgpt-prompt-rules.png)

| ルール | 悪い例 | 良い例 |
|---|---|---|
| **①役割を与える** | メール書いて | あなたはプロのビジネスライターです。メールを書いてください |
| **②条件を具体的に** | 短く | 300文字以内で |
| **③出力形式を指定** | まとめて | 箇条書きで5つ |
| **④背景を伝える** | 企画書作って | 社内プレゼン用の企画書（聴衆はITに詳しくない経営層） |
| **⑤ダメなら修正** | （そのまま使う） | もう少しカジュアルに。具体例を2つ追加して |

## メール作成（5選）

### ①日程変更のお願い

```
あなたはプロのビジネスライターです。以下の条件でメールを作成してください。

【宛先】取引先の田中様
【目的】来週の打ち合わせ日程の変更依頼
【理由】社内会議と重複
【希望日】水曜14時 or 木曜10時
【トーン】丁寧なビジネスメール
【文字数】200文字以内
```

### ②お礼メール

```
以下の条件でお礼メールを作成してください。

【宛先】昨日の商談相手（初対面）
【内容】商談のお礼＋次回アクションの確認
【次回】来週月曜に見積もりを送る予定
【トーン】丁寧だが堅すぎない
```

### ③断りメール

```
以下の条件で丁寧な断りメールを作成してください。

【宛先】営業の方からの提案
【断る理由】予算の都合上、今期の導入は見送りたい
【関係性】将来の可能性は残したい
【トーン】丁寧で相手を不快にさせない
```

### ④催促メール

```
以下の条件で催促メールを作成してください。

【宛先】社外の担当者
【内容】先週依頼した資料がまだ届いていない
【期限】今週金曜まで
【トーン】角が立たないよう柔らかく
```

### ⑤謝罪メール

```
以下の条件で謝罪メールを作成してください。

【宛先】クライアント
【内容】納品物に誤りがあったことへの謝罪
【対応】修正版を本日中に再送
【トーン】誠実で具体的な対応策を示す
```

## Excel・データ分析（5選）

### ⑪Excel関数

```
Excelで以下の処理をしたいです。関数を教えてください。

【データ】A列に日付、B列に商品名、C列に売上金額
【やりたいこと】商品名ごとに月別の売上合計を出したい
【出力】D列以降に結果を表示
```

### ⑫VBAマクロ

```
ExcelのVBAマクロを作成してください。

【やりたいこと】毎月のレポートシートを自動で複製し、日付を更新する
【詳細】「テンプレート」シートをコピー → シート名を「2026年5月」に → A1セルに「2026年5月度レポート」と入力
```

### ⑬データのクリーニング

```
以下のデータに問題があります。修正方法を教えてください。

【問題】氏名の列に全角・半角スペースが混在している
【ツール】Excel
【期待する結果】スペースを統一して名字と名前を分割
```

### ⑭グラフの種類を選ぶ

```
以下のデータを可視化したいです。最適なグラフの種類と理由を教えてください。

【データ】過去12ヶ月の売上推移（月別）＋前年同月比
【聴衆】経営会議の参加者
【目的】売上の成長トレンドを伝えたい
```

### ⑮ピボットテーブルの作り方

```
Excelのピボットテーブルの作り方をステップバイステップで教えてください。

【データ】A列:日付、B列:担当者、C列:商品、D列:売上
【分析したいこと】担当者別×月別の売上合計
【スキルレベル】Excelは基本操作のみ
```

## よくある質問

### Q. プロンプトをそのままコピペしていい？

してOKです。ただし【】内を自分の仕事に合わせて書き換えてください。具体的な条件を入れるほど回答の精度が上がります。

> 💡 **AIの出力は必ず確認を**：ChatGPTは事実と異なる情報をもっともらしく書くことがあります（ハルシネーション）。特にビジネスで使う数字・法律・社名などは、必ず人間がファクトチェックしてから使ってください。

### Q. うまく回答が出ないときは？

「もう少し具体的に」「箇条書きで」「初心者向けに」など、**追加の指示を出して修正**してください。1回で完璧な回答は出ません。対話しながら仕上げるのが基本です。
