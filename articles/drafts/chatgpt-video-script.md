YouTube動画の台本作成に**2時間かかっていた作業が、ChatGPTで15分**に短縮できます。

この記事では、企画→構成→台本の3ステップをChatGPTで効率化する方法と、**コピペで使えるプロンプト**を紹介します。

**この記事でわかること：**
- ChatGPTで動画台本を作る3ステップ
- ネタ出し・構成・台本のプロンプト7個
- 台本の品質を上げるコツ


## ChatGPTで台本を作る3ステップ

![ChatGPTで動画台本を作る3ステップ](UPLOAD_URL:chatgpt-script-3steps.png)

| ステップ | ChatGPTにやらせること | 人間がやること |
|---|---|---|
| **1. 企画** | ネタ出し・ターゲット分析 | 最終的なテーマ選定 |
| **2. 構成** | 導入→本題→まとめの骨子 | 流れの確認・修正 |
| **3. 台本** | セリフ・説明文の下書き | 自分の言葉に書き換え |

> 💡 **大前提**：ChatGPTの出力を**そのまま読み上げるのはNG**です。AIの文章は「正しいけど面白くない」傾向があります。必ず自分の言葉、自分の体験に書き換えてください。

## ステップ1：企画を考える

### プロンプト①：ネタ出し

```
あなたはYouTubeの企画プロデューサーです。

以下の条件で動画企画を10個考えてください。

【チャンネルテーマ】動画編集の始め方（初心者向け）
【ターゲット】30代会社員。副業に興味がある
【条件】
・再生されやすいタイトル案を含める
・各企画に「なぜこの企画が再生されるか」の理由を添える
・競合が少なそうなニッチなテーマも2つ入れる
```

### プロンプト②：ターゲット分析

```
以下のYouTube動画のターゲットを分析し、ペルソナを作成してください。

【動画テーマ】動画編集の副業で月5万円稼ぐ方法
【出力】
・ペルソナ（名前・年齢・職業・悩み・YouTubeの視聴習慣）
・この人が動画を見る動機
・この人が最後まで見てくれる条件
```

## ステップ2：構成を作る

### プロンプト③：動画の構成

```
以下のYouTube動画の構成を作成してください。

【タイトル】動画編集の副業で月5万円稼ぐ方法【初心者向け】
【ターゲット】30代会社員、動画編集未経験
【動画尺】10分
【構成ルール】
・冒頭15秒で視聴者の悩みに共感
・「結論を先に」の構成
・各セクションに時間配分を記載
・最後に次の動画への誘導
```

### プロンプト④：サムネイル＋タイトル案

```
以下の動画のサムネイルとタイトルの案を5パターン作ってください。

【動画内容】動画編集の副業で月5万円稼ぐ方法
【条件】
・タイトルは40文字以内
・サムネイルは「キャッチコピー＋ビジュアルイメージ」で記述
・クリック率が高そうな順に並べて、理由も添える
```

## ステップ3：台本を書く

### プロンプト⑤：台本の下書き

```
以下の構成をもとに、YouTube動画の台本を作成してください。

【構成】
（ステップ2で作った構成をここに貼り付け）

【ルール】
・話し言葉で書く（「〜です」「〜ですよね」）
・1文は短く。40文字以内
・具体例や数字を入れる
・テロップで強調すべき箇所を【テロップ：◯◯】で示す
・B-roll（差し込み映像）の指示を[B-roll: ◯◯]で示す
・10分尺に収まる分量（約3,000文字）
```

### プロンプト⑥：導入（フック）の強化

```
以下のYouTube動画の冒頭15秒の台本を5パターン作ってください。

【動画テーマ】動画編集の副業で月5万円稼ぐ方法
【条件】
・視聴者の離脱を防ぐフック（引き）を入れる
・「自分ごと」と感じさせる
・15秒以内（約60文字）
・最も効果的だと思うパターンに★を付けて理由も添える
```

## 台本の品質を上げるコツ

| コツ | 詳細 |
|---|---|
| **自分の体験を入れる** | AIは一般論しか書けない。「自分が月5万稼いだとき◯◯した」のような体験を追加 |
| **口語に書き換える** | AI文は書き言葉になりがち。声に出して読んで不自然な箇所を修正 |
| **具体的な数字を入れる** | 「たくさん」→「月5万円」「3ヶ月」のように数字に置き換え |
| **段階的に深掘りする** | 1回のプロンプトで完成させず、「もっとカジュアルに」「具体例を追加」と対話で仕上げる |

> 💬 **現場の本音**：プロのYouTuberは台本を「AIに50%書かせて、残り50%を自分の言葉に書き換える」使い方をしています。100%AIは不自然、100%手書きは非効率。この50:50が最適解です。

## ショート動画の台本

### プロンプト⑦：ショート動画用

```
以下のテーマで60秒のショート動画の台本を作成してください。

【テーマ】Premiere Proの時短テクニック
【構成】フック（3秒）→ 本題（50秒）→ CTA（7秒）
【ルール】
・最初の3秒で「え？そうなの？」と思わせる
・1つのテクニックに絞る
・テロップ指示を入れる
・最後に「フォローしてね」
```

## よくある質問

### Q. ChatGPTで作った台本をそのまま使っていい？

**そのまま使うのはおすすめしません。** AI文はどれも似た雰囲気になり、視聴者に「AIっぽい」と感じさせます。必ず自分の言葉・体験・感情を入れて書き換えてください。

### Q. 台本なしで話す方がいい？

台本は「話す内容のガイド」です。一字一句読むのではなく、要点を確認しながら自分の言葉で話すのが理想。ChatGPTで作った構成メモを手元に置いて撮影するスタイルがおすすめ。
