動画編集に使う素材（動画、BGM、効果音、画像）は**すべて無料で揃います**。この記事では商用利用OKの無料素材サイトを4ジャンルに分けてまとめました。

## 動画素材（映像クリップ）

| サイト | 商用利用 | 特徴 |
|---|---|---|
| **[Pexels](https://www.pexels.com/ja-jp/videos/)** | ◎ OK | 高品質。カテゴリ検索が便利 |
| **[Pixabay](https://pixabay.com/ja/videos/)** | ◎ OK | 動画・画像・音楽すべて揃う |
| **[Mixkit](https://mixkit.co/)** | ◎ OK | カテゴリ別に整理。ダウンロード簡単 |
| **[Coverr](https://coverr.co/)** | ◎ OK | Webサイト用のおしゃれな素材 |

練習用の使い方 → [練習素材はどこで手に入る？](/video-editing-practice-materials/)

## 著作権の注意点

| ルール | 内容 |
|---|---|
| **利用規約を確認** | サイトごとに条件が異なる |
| **クレジット表記** | 不要のサイトが多いが、必要な場合もある |
| **再配布禁止** | 素材そのものを他人に渡すのはNG |
| **AI生成素材** | 利用規約が流動的。仕事使用は要注意 |

> ⚠️ **よくある落とし穴**：YouTubeやSpotifyで流れている市販の曲を無断で使うのは**著作権侵害**です。必ずフリー素材サイトから入手してください。

## 有料素材サイト（もっと品質を求めるなら）

| サイト | 料金 | 特徴 |
|---|---|---|
| **Artlist** | 年約2万円 | 高品質BGM。映像クリエイター向け |
| **Epidemic Sound** | 月約1,500円〜 | 4万曲以上。YouTuber人気No.1 |
| **Envato Elements** | 月約2,000円〜 | BGM＋動画＋テンプレートまとめて |

> 💬 **現場の本音**：副業で月5万円以上稼いでいるなら有料サイトに投資する価値があります。曲探しの時間が半分になり、品質も段違い。
