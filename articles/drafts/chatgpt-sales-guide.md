> 💬 **現場の本音**：営業でChatGPTを使う最大の注意点は、**AIが出した企業情報を鵜呑みにしないこと**です。企業名・売上・最新ニュースは必ず公式サイトやIR情報で裏取りしてください。間違った情報で商談に臨むと信頼を失います。

## 商談準備に使うプロンプト

### ①企業リサーチ

```
以下の企業について、営業商談に必要な情報を整理してください。

【企業名】◯◯株式会社
【調べてほしいこと】
・事業内容と主要サービス
・最近のニュース・プレスリリース
・業界での立ち位置・競合
・抱えていそうな課題（推測でOK）
・商談で使えそうなフックポイント
```

### ②業界分析

```
以下の業界の最新トレンドを営業提案に使える形で整理してください。

【業界】製造業（中小企業）
【出力形式】
・業界の課題TOP3
・各課題に対して当社のサービスがどう貢献できるか
・商談で使える「刺さるフレーズ」を3つ
```

## 営業メールに使うプロンプト

### ③初回アプローチメール

```
以下の条件で営業メールを作成してください。

【宛先】◯◯株式会社 マーケティング部 山田様
【当社サービス】AI活用の業務効率化コンサルティング
【フック】先日のプレスリリースで新規事業立ち上げを拝見
【目的】30分のオンライン面談の依頼
【トーン】丁寧だが堅すぎない。相手の興味を引く
【文字数】200文字以内
```

### ④フォローアップメール

```
以下の条件でフォローアップメールを3パターン作成してください。

【状況】初回提案から1週間、返信なし
【パターン】
1. 追加情報を提供する形
2. 業界の最新事例を共有する形
3. 期限を設定する形
【トーン】押し売りにならず、相手にとって価値がある内容
```

## 商談で使うプロンプト

### ⑤想定Q&A

```
以下の商談に向けて、想定される質問と回答を10個作成してください。

【提案内容】AIチャットボットの導入（月額5万円）
【相手】中小企業の経営者（ITに詳しくない）
【想定される反論】「高い」「うちにAIは早い」「効果が見えない」
【出力形式】質問→回答→回答のポイント の3点セット
```

### ⑥トークスクリプト

```
以下の条件で商談のトークスクリプトを作成してください。

【商材】業務効率化ツール（月額3万円）
【相手】製造業の部長クラス
【時間】30分
【構成】
・アイスブレイク（2分）
・ヒアリング（10分）
・提案（10分）
・クロージング（5分）
・次のステップ確認（3分）
```

## 提案書に使うプロンプト

### ⑦提案書の骨子

```
以下の条件で提案書の骨子を作成してください。

【提案内容】AI導入による営業部門の業務効率化
【クライアント】従業員200名のBtoB企業
【課題】営業の事務作業に時間がかかり、商談件数が伸びない
【予算】月額10万円以内
【出力形式】スライド10枚分の見出しと各ページの要点
```

### ⑧競合比較資料

```
当社サービスと競合3社の比較資料を作成してください。

【当社の強み】導入が簡単、サポートが手厚い、月額が安い
【競合】A社（機能が多い）、B社（知名度が高い）、C社（無料プランあり）
【出力形式】比較表＋当社を選ぶべき理由の3行まとめ
```

## フォローに使うプロンプト

### ⑨商談議事録

```
以下の商談メモを整理して議事録を作成してください。

【出力形式】
1. 日時・参加者
2. ヒアリング内容（課題・要望の要約）
3. 提案内容の要約
4. 先方の反応・懸念点
5. ネクストアクション（担当・期限付き）

【メモ】
（商談中のメモをここに貼り付け）
```

### ⑩お礼＋次回アクション確認

```
以下の条件で商談後のお礼メールを作成してください。

【相手】◯◯株式会社 田中部長
【商談内容】AI導入の初回提案
【次のアクション】来週月曜に見積書を送付
【トーン】丁寧かつ信頼感を与える
```

> 💡 **トップ営業の使い方**：ChatGPTは「商談の準備時間を半分にして、その分クライアントと向き合う時間を増やす」ためのツールです。AIに任せるのは事務作業、人間がやるのは信頼構築——この使い分けが成果を出すコツです。

## 注意点

| 注意点 | 対策 |
|---|---|
| **機密情報の入力** | 顧客の未公開情報や個人情報はAIに入力しない（個人情報保護法に抵触する可能性あり） |
| **事実確認** | AIが生成した企業情報・数値は必ず公式サイトで確認 |
| **AI依存しすぎない** | 提案のロジックは人間が考える。AIは作業のアシスタント |
