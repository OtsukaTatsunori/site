## Suno AIでBGMを作る手順

### ステップ1：ログイン

suno.comにアクセスし、GoogleアカウントまたはDiscordでログイン。

### ステップ2：プロンプトを入力

| 項目 | 入力例 |
|---|---|
| ジャンル | Lo-fi chill hop |
| 雰囲気 | relaxing, warm, cozy |
| テンポ | 80 BPM, slow |
| 楽器 | piano, soft drums, bass |
| 用途 | background music for YouTube video |

**プロンプト例**：
```
Lo-fi chill hop, relaxing piano melody,
soft drums, warm bass, cozy atmosphere,
80 BPM, instrumental only,
perfect for YouTube background music
```

### ステップ3：生成＆ダウンロード

「Create」ボタンで生成（約30秒）。気に入った曲をダウンロードして動画編集ソフトに読み込み。

## 動画用BGMを作るコツ

| コツ | 詳細 |
|---|---|
| **instrumental only を指定** | 歌声なしのBGMにするため |
| **テンポを動画に合わせる** | 解説系 → 80〜100 BPM / テンポ良い系 → 120〜140 BPM |
| **ループしやすい曲を選ぶ** | 同じ曲を繰り返し使える |
| **複数バリエーション作る** | 同じプロンプトで何度か生成し、ベストを選ぶ |
| **音量は-20dBに** | BGMはナレーションの邪魔にならないよう小さめに |

## よくある質問

### Q. 無料で使えるAI BGMツールはある？

各ツールに無料枠はありますが、**商用利用（YouTube等）は有料プランが必要**です。月$10程度で無制限に生成できるので、動画をコンスタントに作るならすぐに元が取れます。

### Q. 音楽の知識がなくても使える？

使えます。「relaxing piano BGM for YouTube」のように日本語や英語で雰囲気を伝えるだけでOKです。
