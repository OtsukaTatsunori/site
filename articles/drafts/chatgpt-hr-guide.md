人事の仕事は「人と向き合う時間」が最も大切です。しかし現実には、**求人票の作成、書類選考、研修資料づくり、評価コメントの下書き**など、事務的な作業に時間を取られている方が多いのではないでしょうか。

ChatGPTを使えば、こうした**定型的な作業を大幅に時短**できます。この記事では、人事業務の各フェーズで使える具体的なプロンプトと注意点を紹介します。

## 求人票の作成に使うプロンプト

求人票は「応募者に刺さる表現」と「正確な条件記載」の両方が必要です。ChatGPTを使えば、たたき台を素早く作れます。

### プロンプト例：求人票の生成

```
以下の条件で、求人票の原稿を作成してください。

【職種】経理担当
【雇用形態】正社員
【勤務地】東京都港区（リモートワーク週2日可）
【年収】400万〜550万円
【必須スキル】日商簿記2級以上、月次決算の経験
【歓迎スキル】連結決算の経験、英語での経理業務
【会社の特徴】設立10年のITベンチャー、社員数80名
【出力形式】
・キャッチコピー（30字以内）
・仕事内容（箇条書き）
・求める人物像
・福利厚生
・応募者に伝えたいメッセージ（200字程度）
```

> 💡 **ポイント**：求人票は生成したまま使わず、**自社の雰囲気や実際の業務内容と照らし合わせて必ず修正**してください。特に給与・待遇の記載は法律に関わるため、人間の目で最終チェックが必須です。

### 求人票のブラッシュアップ

一度生成した求人票は、以下のプロンプトでブラッシュアップできます。

```
この求人票を以下の観点で改善してください。
・20代後半〜30代前半のエンジニアに響く表現に調整
・福利厚生を具体的な数字で補足
・「堅苦しすぎる」部分をカジュアルに修正
```

## 面接質問の設計

面接の質問は、職種や評価したいスキルに応じて毎回考える必要があります。ChatGPTで質問リストを作り、そこから選ぶ方式が効率的です。

### プロンプト例：面接質問リストの生成

```
以下の条件で、面接用の質問リストを作成してください。

【職種】法人営業（SaaS）
【評価したい能力】
①課題発見力 ②提案力 ③粘り強さ
【質問形式】STAR法（状況→課題→行動→結果）で回答を引き出せる質問
【出力形式】
・能力ごとに3問ずつ
・各質問に「この質問で見極められること」を添付
・評価基準（◎○△×）の目安も記載
```

| 評価項目 | 質問の狙い | 見極めるポイント |
|---|---|---|
| 課題発見力 | 過去の経験から問題を発見した場面を聞く | 自ら気づけるか・指示待ちか |
| 提案力 | 解決策をどう考え、どう伝えたかを聞く | 論理性・相手目線の有無 |
| 粘り強さ | 失敗や拒否に対してどう行動したかを聞く | 諦めない姿勢・改善行動の有無 |

> 💬 **現場の本音**：面接官によって質問のレベルがバラバラになるのは、多くの企業が抱える課題です。ChatGPTで**統一された質問リストを事前に共有**しておけば、面接の品質が安定します。特に現場マネージャーが面接に参加するケースで効果的です。

## 研修資料の作成

新入社員研修や中途入社者向けオンボーディング資料の作成にもChatGPTは活躍します。

### プロンプト例：研修カリキュラムの設計

```
以下の条件で、新入社員向けビジネスマナー研修のカリキュラムを作成してください。

【対象】新卒入社の社員20名
【期間】1日（6時間）
【目的】社会人としての基本マナーと、自社の行動指針を理解する
【出力形式】
・タイムテーブル（時間割）
・各セッションの目的と内容
・ワークショップの具体的な進め方
・使用する配布資料の構成案
```

### 研修資料の骨子を一括生成

カリキュラムが決まったら、各セッションの資料も一括で下書きできます。

```
上記カリキュラムのセッション2「ビジネスメールの書き方」について、
以下を作成してください。
・スライド10枚分の見出しと要点
・良い例と悪い例のメール文面（各2パターン）
・受講者向けの演習課題
```

## 評価コメントの下書き

半期・四半期ごとの人事評価は、**全社員分のコメントを書く最も時間がかかる業務**の一つです。

### プロンプト例：評価コメントの下書き

```
以下の情報をもとに、上司から部下への評価コメント（200字程度）を作成してください。

【被評価者】営業部 鈴木さん（3年目）
【評価期間】2026年上半期
【目標と実績】
・売上目標：2,000万円 → 実績：2,400万円（達成率120%）
・新規顧客獲得：10社 → 実績：8社（達成率80%）
【良かった点】既存顧客の深耕で大型案件を受注
【課題】新規開拓のアプローチ数が少ない
【トーン】前向きで、改善点は具体的なアドバイスを含む
```

> 💡 **重要な注意点**：評価コメントはAIの出力をそのまま使わないでください。**ChatGPTは本人のことを知りません**。あくまで「たたき台」として使い、あなたが実際に見てきた本人の行動・姿勢を反映させて仕上げてください。

## 社内FAQ対応

就業規則、福利厚生、有給休暇、育休制度——人事部には毎日同じような質問が届きます。

### ChatGPTでFAQを体系化する

```
以下の社内規定の内容をもとに、社員向けFAQを作成してください。

【トピック】有給休暇制度
【規定の内容】
・入社6ヶ月後に10日付与
・勤続年数に応じて最大20日
・半日単位の取得可
・時間単位の取得は年5日まで
・繰越は翌年まで（最大40日）
・5日の計画的付与あり

【出力形式】
Q&A形式で10問。社員が実際に聞きそうな質問にしてください。
```

## 個人情報の取り扱いに関する重要な注意点

人事業務では個人情報を扱う場面が多いため、ChatGPTの利用には**特に慎重な対応が必要**です。

| やってよいこと | やってはいけないこと |
|---|---|
| 架空の名前・条件で下書きを生成 | 実際の社員の名前・評価をそのまま入力 |
| 一般的な質問リストの作成 | 応募者の履歴書をコピペして要約 |
| 制度の説明文を作成 | 社員の個人情報（住所・給与等）を入力 |
| 研修カリキュラムの設計 | 社内の機密情報をプロンプトに含める |

**対策として推奨される方法：**

- **ChatGPT Team/Enterprise版**を利用する（入力データが学習に使われない）
- **Azure OpenAI Service**を経由する（自社テナント内で処理）
- プロンプトには**匿名化した情報**のみ入力する
- 社内ガイドラインを策定し、全員に周知する

## よくある質問

### Q. ChatGPTで作った求人票をそのまま掲載して大丈夫？

そのまま掲載するのは避けてください。法律上、求人票には**正確な労働条件の記載が義務づけられています**（職業安定法第5条の3）。給与、勤務時間、社会保険などの条件は必ず人間の目で事実確認してください。ChatGPTはあくまで「文面のたたき台」として使うのが安全です。

### Q. 評価コメントをAIに書かせたことが部下にバレたら問題になる？

ChatGPTは「下書き」を作るだけで、最終的な評価は上司が責任を持って仕上げるものです。要は**中身の質**が問われます。テンプレート的な文章をそのまま使えばバレますし、本人の行動を具体的に反映させていれば問題になりません。**AIを使ったかどうかより、評価の内容が適切かどうか**が重要です。

### Q. 無料版のChatGPTでも人事業務に使える？

使えます。ただし、**無料版はOpenAIのサーバーにデータが送信される**ため、個人情報を入力しないでください。有料のTeamプラン（1ユーザー月額$25〜）やEnterprise版なら、データが学習に使用されない保証があります。まずは無料版で架空データを使って練習し、本格導入時は有料プランを検討するのがおすすめです。
