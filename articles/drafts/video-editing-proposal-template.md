「応募しても全然通らない」——原因の9割は**提案文の書き方**です。

動画編集のスキルがあっても、提案文が弱ければ案件は取れません。この記事では、**通過率を3倍に上げる提案文の書き方とテンプレート**を紹介します。

## 通らない提案文の3つの特徴

### 特徴1：テンプレのコピペ丸出し

```
はじめまして。動画編集できます。
ぜひお仕事させてください。
```

**何ができるか、なぜこの案件に応募したかが伝わらない。** 発注者は1案件に20〜50件の応募を受けます。この内容では読み飛ばされます。

### 特徴2：自分の話ばかり

```
私は動画編集歴3ヶ月で、Premiere Proを使っています。
After Effectsも勉強中です。趣味は映画鑑賞です。
```

**発注者が知りたいのは「あなたが何者か」ではなく「自分の課題を解決してくれるか」**です。

### 特徴3：ポートフォリオがない

どれだけ良い文章を書いても、**「作品を見せてください」→「ありません」で終了**です。

## 通る提案文のテンプレート 3パターン

### パターン1：YouTube編集案件向け

```
◯◯様

チャンネルを拝見しました。
「△△」の動画は構成がわかりやすく、
特にテロップのテンポが視聴者を飽きさせない
素晴らしい作りだと感じました。

■ この案件に応募した理由
◯◯様のチャンネルのテーマに共感しており、
編集で魅力をさらに引き出せると考えています。

■ 対応可能な編集
・カット編集（ジャンプカット対応）
・テロップ挿入（フル字幕 or ポイント字幕）
・BGM・効果音
・カラー補正
・サムネイル制作（Canva使用）

■ 使用ソフト
Adobe Premiere Pro

■ 納期
素材受領後3営業日以内

■ ポートフォリオ
（YouTube限定公開リンク）

ご検討いただけますと幸いです。
```

### パターン2：ショート動画案件向け

```
◯◯様

ショート動画の編集案件に応募いたします。

TikTok・Reels・YouTube Shortsの
縦型編集に対応可能です。

■ 対応内容
・縦型（9:16）のカット編集
・テロップ挿入（画面中央、大文字）
・トレンドBGMの選定
・トランジション

■ 強み
最初の1秒で視聴者を惹きつける
「フック」の構成を意識した編集が得意です。

■ ポートフォリオ（ショート動画）
（リンク）

■ 納期
素材受領後2営業日以内
```

### パターン3：企業案件向け

```
ご担当者様

貴社の動画編集案件に応募いたします。

■ 対応可能な編集
・カット編集、テロップ、BGM、カラー補正
・サムネイル制作
・企画構成のご提案も可能です

■ 使用ソフト
Adobe Premiere Pro / After Effects

■ 実績
YouTube編集：月間◯本の継続案件を◯社担当
ショート動画：◯本の制作実績

■ 納期
内容によりますが、目安として
素材受領後5営業日以内

■ ポートフォリオ
（リンク）

まずは1本テスト納品でお試しいただければ幸いです。
ご検討のほどよろしくお願いいたします。
```

## 提案文カスタマイズの3つのコツ

### コツ1：最初の2行で「見た」ことを示す

> 💬 **現場の本音**：提案文の**最初の2行が勝負**です。「チャンネルを拝見しました。〇〇の動画が印象的でした」——この1文があるだけで「テンプレじゃない」と伝わり、読み進めてもらえます。5分で1本見るだけです。

### コツ2：相手の課題を推測して書く

「編集者を探している」ということは、**自分で編集する時間がない or スキルがない**ということ。「◯◯様の負担を減らせるよう、迅速かつ丁寧に対応いたします」の一文が刺さります。

### コツ3：「テスト1本」を提案する

「まず1本お試しで編集させてください」と提案すると、**発注者のリスクが下がり、OKが出やすくなります**。ただし「無料で1本」はNG。「通常料金でテスト納品」が正解です。

## やってはいけない5つのNG

| NG | 理由 |
|---|---|
| 「何でもやります」 | 何が得意かわからない |
| 料金を書かない | 発注者が判断できない |
| ポートフォリオなし | スキルが証明できない |
| 長すぎる（1,000字超） | 読まれない |
| 誤字脱字がある | 「この人に任せて大丈夫？」と思われる |

## よくある質問

### Q. 何件送れば1件通る？

**初心者は30〜50件に1件**が目安。提案文を改善するたびに通過率は上がります。

### Q. 同じ提案文を使い回してもいい？

**構成（テンプレート）は使い回しOK。ただし「最初の2行」は毎回書き換える**。ここが使い回しだと一瞬でバレます。

### Q. 単価はいくらで提案すべき？

初心者は**1本5,000〜8,000円**が現実的。案件の予算が明記されている場合は、予算内で提案してください。

## まとめ

| ポイント | 内容 |
|---|---|
| 最初の2行 | 「相手を見た」ことを示す |
| 構成 | 理由→対応内容→ソフト→納期→ポートフォリオ |
| カスタマイズ | **最初の2行だけ毎回書き換える** |
| NG | テンプレ丸出し、ポートフォリオなし、長すぎ |
