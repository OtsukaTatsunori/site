「100ページのPDF、読む時間がない……」「1時間のYouTube動画、要点だけ知りたい……」

そんな悩みを解決するのが、Googleが無料で提供する**NotebookLM**です。PDFやYouTube動画をアップロードするだけで、AIが内容を理解し、要約・質問応答・ポッドキャスト風の音声解説まで自動生成してくれます。

この記事では、NotebookLMの始め方から実践的な使い方、Geminiとの違いまで詳しく解説します。

## NotebookLMとは？

NotebookLMは、Googleが開発した**ソース特化型AIリサーチツール**です。

通常のAIチャット（ChatGPTやGemini）は「AIが持っている知識」で回答しますが、NotebookLMは**あなたがアップロードした資料だけ**を元に回答します。つまり、ハルシネーション（嘘の回答）が極めて少ないのが最大の特徴です。

| 項目 | 内容 |
|---|---|
| 開発元 | Google |
| 料金 | **無料**（Google アカウントがあればOK） |
| 有料プラン | NotebookLM Plus（月$20） |

> 💬 **現場の本音**：「ChatGPTに長いPDFを読ませたら、途中から内容が飛ぶ」という経験がある人も多いはず。NotebookLMは**ソースの内容を正確に読み込む**ことに特化しているため、抜け漏れが圧倒的に少ないです。

## NotebookLMの始め方【3ステップ】

### ステップ1：Googleアカウントでログイン

1. [NotebookLM公式サイト](https://notebooklm.google.com)にアクセス
2. Googleアカウントでログイン（Gmailがあれば誰でも使えます）
3. 「新しいノートブック」をクリック

### ステップ2：ソースをアップロード

以下のいずれかをアップロードします。

| ソースの種類 | アップロード方法 |
|---|---|
| **PDF** | ファイルをドラッグ＆ドロップ、またはアップロードボタン |
| **Webページ** | URLを貼り付け |
| **YouTube動画** | 動画のURLを貼り付け（字幕があるものに限る） |
| **Googleドキュメント** | Googleドライブから直接選択 |
| **テキスト** | コピーしたテキストを貼り付け |

### ステップ3：AIに質問する

チャット欄に質問を入力するだけ。回答にはすべて**引用元（ソースの該当箇所）**が表示されるため、「この情報はどこに書いてあったか」がすぐわかります。

> 💡 **活用のコツ**：最初にソースをアップロードしたら、まず「このドキュメントの要点を5つにまとめて」と聞いてみましょう。全体像を把握してから深掘りすると効率的です。

## NotebookLMの4大機能

### 機能1：AIによる要約

ソースをアップロードすると、自動で「ソースガイド」が生成されます。これがドキュメント全体の要約です。さらに、チャットで「3行で要約して」「初心者向けに解説して」など、要約の粒度を指示できます。

### 機能2：質問応答（引用付き）

チャットで自由に質問できます。すべての回答に**ソースの引用番号**がつくため、原文をすぐに確認できます。

**使える質問の例：**

- 「この資料の結論は？」
- 「AとBの違いを表にして」
- 「この議事録の決定事項をリストアップして」
- 「この論文の研究手法を初心者向けに説明して」

### 機能3：音声概要（Audio Overview）

アップロードしたソースの内容を、**2人のホストが対話形式で解説するポッドキャスト風の音声**を自動生成してくれる機能です。

| 項目 | 内容 |
|---|---|
| 生成時間 | 数分 |
| 音声の長さ | 5〜15分程度 |
| 言語 | 英語が中心（日本語ソースでも英語になることがある） |
| カスタマイズ | 「初心者向けに」「特定のトピックに焦点を当てて」などの指示が可能 |

> 💬 **現場の本音**：音声概要は「通勤中に資料の概要をつかむ」のに最適です。ただし、2026年4月時点では日本語音声の品質はまだ発展途上。英語のソースならかなり自然な音声が生成されます。

### 機能4：ノートの作成・整理

質問の回答を「ノート」として保存し、後から見返したり、整理・統合したりできます。研究や調査のメモ帳として機能します。

## 実践：こんな場面で使える

| 場面 | 使い方 | 効果 |
|---|---|---|
| **会議の議事録を読む** | PDF/テキストをアップして「決定事項をリストアップ」 | 30分の議事録を1分で把握 |
| **論文を読む** | PDFをアップして「研究結果を3行で要約」 | 難解な論文もすぐ理解 |
| **YouTube講義の復習** | URLを貼って「重要ポイントを箇条書きで」 | 1時間の動画を3分で復習 |
| **契約書のチェック** | PDFをアップして「リスクのある条項を抽出」 | 重要箇所の見落とし防止 |
| **複数資料の比較** | 複数PDFをアップして「AとBの違いは？」 | 横断的な分析が一瞬で |

> 💡 **活用のコツ**：NotebookLMは**複数ソースの横断検索**が得意です。例えば、競合3社の決算書をすべてアップロードして「3社の売上成長率を比較して」と聞けば、一覧表を作ってくれます。

## NotebookLM vs Gemini｜どっちを使うべき？

| 比較項目 | NotebookLM | Gemini |
|---|---|---|
| 情報源 | **アップロードした資料のみ** | Web全体＋AIの知識 |
| ハルシネーション | 極めて少ない | 一般的なAI並み |
| 引用の正確さ | ◎（引用箇所を明示） | △（出典が曖昧なことも） |
| Web検索 | × | ◎ |
| 画像生成 | × | ○ |
| 音声生成 | ◎（Audio Overview） | × |
| 料金 | 無料 | 無料（Advanced 約2,900円/月） |
| 向いている用途 | 資料の精読・要約・分析 | 調べ物・文章生成・日常利用 |

**使い分けの結論：**

- **手元の資料を正確に分析したい** → NotebookLM
- **Webから最新情報を調べたい** → Gemini
- **文章を書いたり、雑談的に使いたい** → Gemini（または[ChatGPT](/chatgpt-beginner-guide/)）

Geminiの詳しい使い方 → [Gemini初心者ガイド](/gemini-beginner-guide/)

## NotebookLMの注意点・制限

| 注意点 | 詳細 |
|---|---|
| オフライン不可 | インターネット接続が必要 |
| リアルタイム情報なし | アップロードした資料以外の知識は持たない |
| 音声概要の日本語 | 英語中心。日本語は品質が限定的 |
| 無料版の上限 | 1日のクエリ数に制限あり（Plus で緩和） |
| データの保存 | Googleアカウントに紐づく。共有設定に注意 |

## よくある質問

### Q. NotebookLMに入力したデータは学習に使われる？

Googleの公式FAQ によると、アップロードしたデータは**AIモデルの学習には使われない**と明記されています。ただし、利用規約は変更される可能性があるため、機密性の高い情報は社内ポリシーを確認してから利用してください。

### Q. スマホからでも使える？

はい。スマホのブラウザからNotebookLMにアクセスすれば使えます。ただし、PDFのアップロードはパソコンの方がやりやすいため、資料の追加はPCで行い、質問・閲覧はスマホで行うのがおすすめです。

### Q. ChatGPTやClaudeにPDFを読ませるのとどう違う？

大きな違いは**引用の正確さ**です。NotebookLMは回答にソースの引用箇所を明示するため、「この情報は本当にこの資料に書いてあるのか」をすぐ確認できます。ChatGPTやClaudeは回答の根拠が曖昧になりがちです。一方で、文章のリライトや創作は[ChatGPT](/chatgpt-beginner-guide/)や[AIライティングツール](/ai-writing-tools/)の方が得意です。
