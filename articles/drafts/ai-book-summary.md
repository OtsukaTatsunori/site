## AIを使った読書効率化の全体像

![AI読書効率化の方法マップ](UPLOAD_URL:ai-book-summary-map.png)

| 方法 | 向いている場面 | 所要時間 | コスト |
|---|---|---|---|
| **写真→OCR→ChatGPT** | 紙の本の特定章を要約 | 10〜15分 | 無料〜 |
| **Kindle→NotebookLM** | 電子書籍を丸ごと分析 | 5〜10分 | 無料 |
| **flier（本の要約サービス）** | 話題のビジネス書を短時間で把握 | 10分 | 月額2,200円 |
| **ChatGPTに本の概要を聞く** | 読む前の下調べ・購入判断 | 3分 | 無料〜 |
| **読書メモ→ChatGPTで整理** | 読了後の知識定着 | 15分 | 無料〜 |

> 💬 **現場の本音**：AIで本を要約する方法はたくさんありますが、**最も実用的なのは「読む前にChatGPTで概要を掴み、読書中に気になった箇所をNotebookLMで深掘りする」という組み合わせ**です。全部を要約に頼ると「読んだ気になっただけ」で終わります。AIは"読書のナビ"として使うのがコツです。

## 方法1：写真→OCR→ChatGPTで要約

紙の本を持っている場合、スマホで撮影してAIに要約させる方法です。

### 手順

| ステップ | やること | 使うツール |
|---|---|---|
| **1** | 要約したいページをスマホで撮影 | スマホカメラ |
| **2** | 画像からテキストを読み取る（OCR） | Googleレンズ / ChatGPT（画像認識） |
| **3** | 読み取ったテキストをChatGPTに送り、要約を依頼 | ChatGPT |

### ChatGPTの画像認識を使う方法（最も簡単）

2026年現在、ChatGPTはアプリ版・ウェブ版ともに**画像を直接アップロードして読み取る機能**があります。

```
この画像はビジネス書の1ページです。
以下の形式で要約してください。

【要点】3つの箇条書き
【キーワード】重要な用語を5つ
【一言まとめ】30字以内で
【自分のビジネスへの活用アイデア】1つ
```

> 💡 **OCRの精度を上げるコツ**：撮影時は**真上から撮る**、**影が入らないようにする**、**1ページずつ撮る**の3点を守ると、読み取り精度が格段に上がります。斜めから撮ったり、見開きで撮ったりすると、文字がゆがんで誤読の原因になります。

## 方法2：Kindle→NotebookLMで深掘り

GoogleのNotebookLMは、**ドキュメントをアップロードするとAIが内容を分析してくれる無料ツール**です。

### 手順

| ステップ | やること |
|---|---|
| **1** | Kindleのハイライト機能で重要箇所をマーク |
| **2** | [Kindleのメモとハイライト](https://read.amazon.co.jp/notebook) にアクセス |
| **3** | ハイライト部分をコピー |
| **4** | [NotebookLM](https://notebooklm.google.com/) に新規ノートブックを作成 |
| **5** | コピーしたハイライトをソースとして追加 |
| **6** | NotebookLMに質問する |

### NotebookLMで使える質問例

```
・この本の主張を3つにまとめてください
・著者の意見に対する反論として考えられるものは？
・この本の内容を、自分の営業の仕事にどう活かせますか？
・Chapter 3の内容を、上司にプレゼンする場合のスライド構成を考えてください
```

> 💬 **現場の本音**：NotebookLMの強みは**「アップロードした文書の範囲内で正確に回答する」**こと。ChatGPTは学習データ全体から回答するためハルシネーション（嘘の情報を生成すること）のリスクがありますが、NotebookLMはソースに基づいて回答するので、本の内容を正確に引き出せます。

## 方法3：flier（本の要約サービス）との比較

flierは、**プロのライターがビジネス書を1冊10分で読める要約にまとめるサービス**です。

| 比較項目 | ChatGPTで自分で要約 | flier |
|---|---|---|
| **対象** | 手持ちの本なら何でも | flierに掲載されている本のみ（約3,500冊） |
| **要約の質** | プロンプト次第で変動 | プロのライターが執筆、出版社の許可済み |
| **所要時間** | 10〜30分（OCR等の手間あり） | 10分で読める |
| **コスト** | 無料〜（ChatGPT利用料） | 月額2,200円（ゴールドプラン） |
| **著作権** | 自分用ならOK（再配布は不可） | 正式にライセンス取得済み |
| **カスタマイズ** | 自分の仕事に合わせた要約が可能 | 汎用的な要約 |

### 使い分けのおすすめ

- **flierが向いている人**：話題のビジネス書を幅広くチェックしたい人、本を選ぶ前に概要を知りたい人
- **ChatGPT/NotebookLMが向いている人**：特定の本を深く理解したい人、自分の仕事に合わせた要約が欲しい人

> 💡 **賢い使い方**：flierで概要を確認 → 「深く読みたい」と思った本だけ購入 → Kindle版をNotebookLMで深掘り。この流れなら、**読む本の選定も読書そのものも効率化**できます。

## 方法4：読む前にChatGPTで下調べ

本を購入する前、または読み始める前に、ChatGPTで概要を把握しておくと読書効率が大幅に上がります。

### プロンプト例：本の概要を確認

```
以下の本について教えてください。

【書籍名】『イシューからはじめよ』安宅和人
【知りたいこと】
・この本の主張（一言で）
・主要な章の構成と各章のポイント
・この本が特に役立つ読者像
・読む前に知っておくと理解が深まる前提知識
・類似書籍との違い
```

### プロンプト例：目的に合わせた読書プラン

```
以下の本を効率よく読みたいです。
私の目的に合わせて、読むべき章の優先順位をつけてください。

【書籍名】『FACTFULNESS』ハンス・ロスリング
【私の目的】データに基づいた意思決定ができるようになりたい
【確保できる時間】2時間
【出力形式】
・最優先で読む章（30分で）
・次に読む章（余裕があれば）
・スキップしてよい章
```

## 方法5：読書メモ→ChatGPTで整理・定着

本を読んだ後、**メモをChatGPTで整理すると知識の定着率が上がります**。

### プロンプト例：読書メモの整理

```
以下は私が『7つの習慣』を読んで取ったメモです。
これを整理して、以下の形式で出力してください。

【メモ】
・インサイドアウト：自分の内面を変えることで外側が変わる
・影響の輪に集中する、関心の輪を気にしすぎない
・第3の習慣、大事なことを優先する、緊急と重要のマトリクス
・Win-Winを考える、妥協ではなく相互利益
（...以下略）

【出力形式】
① 3行で要約
② 7つの習慣を一覧表にまとめ（習慣名 / 一言説明 / 日常での実践例）
③ 明日から仕事で実践できるアクション3つ
```

## 著作権に関する注意点

AIで本を要約する際は、著作権に配慮する必要があります。

| 行為 | 問題の有無 |
|---|---|
| 自分用にメモ・要約を作る | ○ 問題なし（私的使用） |
| AIに本の内容を入力して質問する | ○ 問題なし（私的使用の範囲） |
| 要約をブログやSNSに公開する | × 著作権侵害のおそれ |
| 要約を社内で共有する | △ 範囲と方法による（引用の要件を満たす必要あり） |
| flierの要約を転載する | × 利用規約違反 |

**基本ルール**：AIで作った要約は**自分の学習用**にとどめてください。ブログやSNSで本の要約を公開するのは、著作権者の許可がない限り避けましょう。

## よくある質問

### Q. AIで要約すると、本を読む意味がなくなるのでは？

なくなりません。AIの要約は「地図」のようなもので、**全体像を把握するには便利ですが、景色（著者の語り口、具体例、行間のニュアンス）は実際に歩かないとわかりません**。AIで概要を掴んでから読むと、むしろ理解が深くなります。「読む必要がない本」を見極めるのにもAIは役立ちます。

### Q. NotebookLMに本をまるごとアップロードしていい？

私的使用の範囲であれば問題ありません。ただし、NotebookLMのサービス利用規約も確認してください。Google側でデータがどう扱われるかは規約に記載されています。心配な方はKindleのハイライト（抜粋）だけをアップロードするのが安全です。

### Q. 技術書やプログラミングの本もAIで要約できる？

できますが、**コードの実践部分はAI要約だけでは身につきません**。概念の理解にはAI要約が有効ですが、プログラミングは「手を動かす」ことが不可欠です。「概念をAIで理解 → コードは自分で書く」の順番がおすすめです。
