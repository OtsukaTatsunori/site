「データ分析って難しそう」——**ChatGPTにCSVファイルを渡すだけで、グラフ作成も傾向分析もやってくれます**。プログラミングは不要です。

## AIデータ分析でできること

| できること | 従来 | AI活用後 |
|---|---|---|
| 売上データの傾向分析 | Excel関数＋ピボット | CSVアップロード→「傾向を分析して」 |
| グラフ作成 | Excel手動 | 「棒グラフにして」で自動 |
| 異常値の検出 | 目視確認 | 「外れ値はある？」で自動 |
| レポート作成 | 手動で報告書 | 「分析結果をレポート形式で」 |

> 💡 **最大のメリット**：分析の専門知識がなくても、**日本語で「やりたいこと」を伝えるだけ**でプロレベルの分析結果が得られます。

## 始め方：3ステップ

### ステップ1：データを用意する

Excelの売上データやアンケート結果をCSVファイルで保存。

### ステップ2：ChatGPTにアップロード

ChatGPT（Plus以上）にCSVファイルをドラッグ＆ドロップ。

### ステップ3：日本語で指示

```
このCSVファイルを分析してください。

1. 月別の売上推移を折れ線グラフで表示
2. 売上が最も高い月と低い月を特定
3. 前年同月比の成長率を計算
4. 売上に影響する要因があれば推測
5. 結果を箇条書きでまとめてください
```

> 💬 **現場の本音**：「データ分析」と聞くと構えますが、やっていることは「Excelの表をChatGPTに見せて質問するだけ」です。SQLもPythonも不要。社内のExcelデータを持っている人なら、今日から使えます。

## プロンプト集

### 売上分析

```
添付のCSVファイルの売上データを分析してください。
・月別推移のグラフ
・商品別の売上構成比
・前月比の成長率
・トップ5商品と下位5商品
```

### アンケート分析

```
添付のアンケートデータを分析してください。
・満足度の平均と分布
・自由回答のキーワード分析（頻出ワードTOP10）
・満足度が低い人の共通点
・改善提案を3つ
```

### 競合分析

```
以下の3社のデータを比較分析してください。
・各社の強み・弱み
・価格帯の比較
・市場シェアの推定
・差別化ポイント
```

## 注意点

| 注意点 | 詳細 |
|---|---|
| **機密データの取り扱い** | 社内データをChatGPTにアップロードする場合、会社のAI利用ポリシーを確認。Team/Enterprise版なら学習に使われない |
| **分析結果の検証** | AIの分析結果は「参考」。重要な意思決定には人間の確認が必須 |
| **ファイルサイズ** | ChatGPTは大きすぎるファイルは処理できない。数万行までが目安 |

> 💡 **プロの使い方**：AIで「仮説」を出してもらい、その仮説をExcelや専門ツールで「検証」するのが効率的です。AIは仮説生成が得意、人間は仮説検証が得意——この役割分担がベスト。

## よくある質問

### Q. 無料版のChatGPTでも使える？

ファイルアップロード機能はPlusプラン（月$20）以上が必要です。ただし、データを直接テキストで貼り付ける方法なら無料版でも使えます。

### Q. プログラミングは必要？

不要です。日本語で「◯◯を分析して」と指示するだけ。Pythonコードが必要な場合も、ChatGPTが自動で書いて実行してくれます。
