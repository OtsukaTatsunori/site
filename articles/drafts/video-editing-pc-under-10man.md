「動画編集を始めたいけど、パソコンに20万円は出せない」

安心してください。**10万円以下でも動画編集は始められます**。ただし「何でもいい」わけではありません。

この記事では、**10万円以下で失敗しないPC選び**のポイントを解説します。

## 10万円以下で「最低限必要な」スペック

| パーツ | 必須ライン | 理想 |
|---|---|---|
| **CPU** | Core i5（第12世代〜）/ Ryzen 5（5000〜） | Core i7 / Ryzen 7 |
| **メモリ** | **16GB**（8GBは不可） | 32GB |
| **ストレージ** | **SSD 256GB以上** | SSD 512GB |
| **GPU** | 内蔵GPUでOK | 専用GPU |

> ⚠️ **よくある落とし穴**：「安い！」と飛びつくと、**メモリ8GB・HDD搭載の古いモデル**を掴みがちです。この2つのどちらかに該当するPCは、動画編集ではほぼ使い物になりません。**メモリ16GB以上・SSD搭載**だけは絶対に妥協しないでください。

## 新品 vs 中古

| 項目 | 新品（10万円以下） | 中古（7〜10万円） |
|---|---|---|
| スペック | Core i5 + 16GB + SSD 256GB | Core i7 + 16GB + SSD 512GB |
| 保証 | 1〜3年 | 3〜6ヶ月 |
| バッテリー | 新品 | 劣化している場合あり |
| コスパ | ○ | ◎（同予算で1ランク上） |

> 💬 **現場の本音**：**予算10万円以下なら中古の方がコスパが良い**です。新品10万円だとCore i5 + 16GB + SSD 256GBが限界ですが、中古なら同じ予算でCore i7 + 32GBが手に入ることもあります。ただしバッテリー劣化と保証期間の短さは覚悟してください。

## 中古PCの選び方

### 買って良い中古PC

- **Core i7 第10世代以降**（型番が10xxx以上）
- **メモリ16GB以上**
- **SSD搭載**
- **整備済み品**（メーカーリファビッシュ or 専門店の整備済み）
- **保証3ヶ月以上**

### 買ってはいけない中古PC

- Core i5 第8世代以前（2018年以前のモデル）
- メモリ8GB（増設不可のモデルは特に危険）
- HDD搭載（SSDに換装されていないもの）
- バッテリー膨張の記載がないが極端に安いもの
- 個人売買（メルカリ等）で保証なし

## 予算別おすすめ構成

### 5〜7万円（最小構成・中古）

| パーツ | スペック |
|---|---|
| 機種 | 中古ノートPC（ThinkPad、HP ProBook等） |
| CPU | Core i7 第10〜11世代 |
| メモリ | 16GB |
| SSD | 256〜512GB |
| GPU | 内蔵 |

**できること：** フルHDのカット編集、テロップ、BGM
**注意：** エフェクト多用やプレビュー再生が重くなる場合あり

### 8〜10万円（おすすめ構成・新品 or 中古）

| パーツ | スペック |
|---|---|
| 機種 | 新品ノートPC（Lenovo IdeaPad、HP Pavilion等） or 中古ハイスペック |
| CPU | Core i5 第12世代〜 / Ryzen 5 |
| メモリ | 16GB |
| SSD | 512GB |
| GPU | 内蔵（新品）or GTX 1650（中古） |

**できること：** フルHD編集は快適。軽い4K編集も可能

> 📝 **ここがポイント**：この価格帯なら**副業で月5万円を稼ぐのに十分なスペック**です。「いいPCを買ってから始める」より「このスペックで今日から始める」方が100倍大事です。

## 10万円以下のPCで快適に編集するコツ

### コツ1：プレビュー解像度を下げる

Premiere Proのプレビュー解像度を「1/2」にするだけで動作が軽くなります。完成品の画質には影響しません。

### コツ2：不要なアプリを閉じる

Chrome等のメモリを食うアプリは編集中は閉じてください。

### コツ3：外付けSSDに素材を保存

PC本体のSSD容量が少ない場合、**外付けSSD（5,000〜8,000円）**に素材を保存して本体の空きを確保してください。

### コツ4：4K素材は避ける

10万円以下のPCで4K素材を編集するのは厳しいです。撮影時に**フルHD（1080p）で撮る**ようにしてください。

## よくある質問

### Q. Chromebookで動画編集はできる？

**基本的にできません。** Premiere ProやDaVinci ResolveはChromebookに非対応です。CapCutのWeb版は使えますが、本格的な編集には不向きです。

### Q. デスクトップの方がコスパ良い？

**はい。** 同じ予算ならデスクトップの方が高いスペックが手に入ります。ただし持ち運べないため、自宅でしか作業しない人向けです。

### Q. 10万円のPCで副業は無理？

**無理ではありません。** フルHDの基本編集（カット＋テロップ＋BGM）は10万円以下のPCで十分こなせます。月5万円の副業収入なら問題ないスペックです。

## まとめ

| 予算 | おすすめ | ポイント |
|---|---|---|
| 5〜7万円 | 中古 Core i7 + 16GB + SSD | 最小限でスタート |
| 8〜10万円 | 新品 Core i5 or 中古ハイスペック | 副業に十分 |

**「PCを買ってから始める」のではなく「今あるPCで始めてみて、足りなければ買い替える」が正解です。**
