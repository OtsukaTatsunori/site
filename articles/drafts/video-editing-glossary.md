動画編集を学んでいると、**聞き慣れない専門用語**がたくさん出てきます。この用語集を**ブックマークして辞書代わり**に使ってください。

## 編集操作の用語

| 用語 | 意味 |
|---|---|
| **カット編集** | 不要な部分を切り取り、流れを整える基本操作 |
| **ジャンプカット** | 話の間や無駄な部分だけを切って前後をつなぐ技法 |
| **トリミング** | クリップの始点・終点を調整して長さを変える |
| **リップル削除** | カットした部分の隙間を自動で詰める操作 |
| **タイムライン** | 動画・音声・テロップを時系列で並べる作業領域 |
| **クリップ** | タイムライン上の動画や音声の1つの断片 |
| **トラック** | タイムライン上の横一列の帯。V1（映像）、A1（音声）等 |
| **再生ヘッド** | タイムライン上の現在位置を示す縦線 |
| **イン点 / アウト点** | 使いたい範囲の始まりと終わりのマーク |
| **ネスト** | 複数のクリップを1つのまとまりにグループ化 |

詳細 → [YouTubeの動画編集のやり方](/youtube-video-editing/)

## テロップ・テキストの用語

| 用語 | 意味 |
|---|---|
| **テロップ** | 画面上に表示するテキスト。字幕とも言う |
| **フル字幕** | 話している内容をすべてテキスト化 |
| **ポイント字幕** | 重要箇所だけテキスト表示 |
| **フォント** | 文字の書体（ゴシック、明朝等） |
| **アウトライン（縁取り）** | 文字の周囲に付ける線。読みやすさUP |
| **ドロップシャドウ** | 文字に影をつけて立体感を出す |

詳細 → [テロップの入れ方](/video-editing-telop/)

## トランジション・エフェクトの用語

| 用語 | 意味 |
|---|---|
| **トランジション** | 場面転換のエフェクト |
| **クロスディゾルブ** | 前後のカットが重なりながら切り替わる |
| **フェードイン / アウト** | 黒画面から徐々に表示 / 徐々に消える |
| **ワイプ** | 画面がスライドして次のカットに |
| **エフェクト** | 映像に加える視覚効果の総称 |
| **キーフレーム** | 動きや変化の開始点と終了点を指定する機能 |
| **モーショングラフィックス** | 文字や図形にアニメーションをつける技法 |

詳細 → [トランジションの種類と使い方](/video-transition-guide/)

## 音声の用語

| 用語 | 意味 |
|---|---|
| **BGM** | 背景音楽 |
| **SE（効果音）** | 「ポン」「シャキン」等のアクセント音 |
| **ノイズ** | 不要な雑音（エアコン音、ホワイトノイズ等） |
| **dB（デシベル）** | 音の大きさの単位。0dBが最大、マイナスで下がる |
| **フェード** | 音量を徐々に上げる（イン）/ 下げる（アウト） |
| **ノーマライズ** | 音量を適正値に自動調整する機能 |
| **サンプルレート** | 音声の品質。48kHzが動画の標準 |

詳細 → [BGMの選び方](/video-editing-bgm-guide/) / [ノイズ除去の方法](/video-editing-noise-removal/)

## 色・映像の用語

| 用語 | 意味 |
|---|---|
| **カラーコレクション** | 撮影時の色のズレを補正する作業 |
| **カラーグレーディング** | 意図的に色味を加えて雰囲気を作る作業 |
| **LUT（ラット）** | 色味のプリセット。ワンクリックで適用 |
| **ホワイトバランス** | 白いものが白く見えるよう色温度を調整 |
| **コントラスト** | 明暗の差。高い＝くっきり、低い＝柔らかい |
| **彩度（サチュレーション）** | 色の鮮やかさ |
| **解像度** | 画面のピクセル数。1920×1080＝フルHD |
| **フレームレート（fps）** | 1秒間の画像枚数。30fps＝1秒に30枚 |
| **アスペクト比** | 画面の縦横比。16:9＝横型、9:16＝縦型 |

詳細 → [カラーグレーディングの基本](/color-grading-beginner/)

## ファイル・書き出しの用語

| 用語 | 意味 |
|---|---|
| **コーデック** | 動画の圧縮方式。H.264が最も一般的 |
| **コンテナ（形式）** | ファイルの入れ物。MP4、MOV等 |
| **ビットレート** | 1秒あたりのデータ量。高い＝高画質だが大容量 |
| **エンコード** | 動画データを圧縮変換する処理 |
| **レンダリング** | エフェクト等を計算して映像に反映する処理 |
| **プロキシ** | 元素材より軽い低解像度のコピー。編集用 |
| **書き出し（エクスポート）** | 完成した動画をファイルとして保存する |

詳細 → [書き出し設定ガイド](/video-export-settings/)

## YouTube関連の用語

| 用語 | 意味 |
|---|---|
| **サムネイル** | 動画の表紙画像。クリック率に直結 |
| **CTR（クリック率）** | サムネイルが表示された中でクリックされた割合 |
| **視聴維持率** | 動画をどれだけ長く見てもらえたかの割合 |
| **チャプター** | 動画の目次。概要欄にタイムスタンプで設定 |
| **エンドカード** | 動画の最後に表示する関連動画やチャンネル登録ボタン |

詳細 → [サムネイル作成のコツ](/youtube-thumbnail-tips/) / [再生回数を伸ばす編集](/youtube-views-editing-tips/)

## ソフトの用語

| 用語 | 意味 |
|---|---|
| **Premiere Pro** | Adobe製。業界標準の動画編集ソフト |
| **After Effects** | Adobe製。モーショングラフィックス・VFX用 |
| **DaVinci Resolve** | 無料で使えるプロ仕様の編集ソフト |
| **CapCut** | スマホ対応。無料。ショート動画向き |
| **パワーコンディショナー** | → 動画編集では**パワコン**ではなく**パワーコンディショナー**は太陽光用語 |
| **Lumetriカラー** | Premiere Proのカラー調整パネルの名前 |
| **Fairlight** | DaVinci Resolveの音声編集ページの名前 |
| **Fusion** | DaVinci ResolveのVFX・モーショングラフィックスページ |
