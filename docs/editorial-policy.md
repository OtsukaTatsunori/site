# 編集方針（エディトリアル・ポリシー）

このドキュメントは「大人の学びなおし比較」で記事を書くときの **上位概念＝考え方の土台** をまとめたものです。

`article-writing-guide.md` が「どう書くか（How）」のテクニカルガイドだとしたら、
こちらは「**何のために書くか（Why）／誰のために書くか（Who）／何を書くか・書かないか（What）**」を定めます。

**記事制作で迷ったら、まずここに戻ってきてください。**

---

## 1. サイトのミッション

> **「大人が学びなおしで失敗しないための、ひとつめに読む場所」をつくる。**

### このサイトが解決したい課題

大人が学びなおしを始めようとしたとき、多くの人が以下の壁にぶつかります。

- **情報が多すぎて選べない** — 学習サービスが無数にあり、比較が難しい
- **料金体系が複雑** — 何が込みで、いくらかかるのか分かりにくい
- **自分に合うか不安** — 40代未経験でもついていけるのか、時間は足りるのか
- **補助金を知らない** — 教育訓練給付金で半額〜7割オフになることを知らない人が多い

「大人の学びなおし比較」は、**この4つの壁を取り払う**サイトです。

## 2. ペルソナ（想定読者）

### メインペルソナ: 30代後半〜50代の社会人

| 属性 | 詳細 |
|---|---|
| 年齢 | 35〜55歳 |
| 職業 | 会社員、公務員、自営業など |
| 悩み | キャリアの頭打ち、AIによる業務変化への不安、副業・転職の選択肢を増やしたい |
| 予算 | 月1〜3万円、または補助金を活用したい |
| 時間 | 平日夜1〜2時間、週末2〜3時間 |
| 情報収集 | スマホ中心（電車内、昼休み、寝る前） |

### サブペルソナ

- **20〜30代前半**: キャリアアップ、スキルアップ、副業開始
- **主婦・主夫**: 在宅でできるスキル習得、復職準備
- **プレ定年層（55歳以上）**: 定年後のセカンドキャリア、教養

### ペルソナ活用のルール

- 記事を書く前に「この記事は、どのペルソナに向けて書くか」を必ず決める
- 同じテーマでも、40代向けと20代向けでは伝える順番・例示・予算感が変わる
- ペルソナが曖昧な記事は刺さらない

## 3. 大切にする5つの価値観

### 価値観1: 読者ファーストで、結果として収益がついてくる

**短期の収益より、読者が本当に得をする情報を優先する。**

アフィリエイト単価の高いサービスを1位に置きたい誘惑は常にあります。
しかしそれをやると、読者の信頼を失い、長期的には検索順位も落ちます。

- ❌ 単価が高いから1位に推す
- ⭕ 読者のニーズに一番合うサービスを1位に推す（結果的に単価が高ければOK）

**判断基準:**
> 「身近な人（例: 親、友人）が同じことで悩んでいたら、自分はこの記事と同じ順序で勧めるか？」
> Yesと言えないなら書き直す。

### 価値観2: 一次情報にこだわる

**公式サイトのコピペでは評価されない。読者が「ここでしか読めない」と思う情報を必ず1つ入れる。**

一次情報の例:
- 実際にサービスを使った体験談・スクリーンショット
- 運営会社に直接問い合わせた回答
- 独自の比較軸（他サイトが比較していない切り口）
- 読者から寄せられた質問への回答

公式サイトの情報は**出典として引用はする**が、それだけでは記事にしない。

### 価値観3: 弱点もはっきり書く

**「このサービスは誰に向いていないか」を必ず書く。**

完璧な学習サービスは存在しません。向き不向きを明示することで、
- ミスマッチによる途中解約を防ぐ
- 読者から「正直なサイトだ」と信頼される
- 結果としてコンバージョン率も上がる

以下のような文は必ず入れる:
> このサービスは◯◯な人には向きません。その場合は[別の選択肢](link)を検討してください。

### 価値観4: 根拠を示す

**断言するときは、根拠を添える。**

- ❌ 「スタディサプリは最もおすすめです」
- ⭕ 「スタディサプリは業界最安値の月額1,980円で、他社平均の約3分の1です。コスパ重視の人には最もおすすめです」

統計や公的データは出典リンクを貼る:
- 厚生労働省
- 経済産業省
- 各社公式サイト
- 公的機関の調査レポート

### 価値観5: 更新を止めない

**一度書いて公開して終わり、にしない。**

- 料金改定、サービス終了、新サービス登場を定期的にチェック
- 3ヶ月に1度、主要記事の情報を更新
- 更新日を記事に明示する（Cocoonで自動表示）

古い情報のまま放置された記事は、読者の信頼とGoogleの評価の両方を失います。

## 4. アフィリエイトに対するスタンス

### 基本方針

**アフィリエイトは記事の目的ではなく、結果である。**

記事の目的は「読者の課題を解決すること」。
解決策として紹介したサービスがたまたまアフィリエイト対象なら、リンクを貼る。
それだけです。

### やること

- アフィリエイト広告を利用していることを**ファーストビューで明示**（ステマ規制対応・Cocoon設定で自動化済み）
- 紹介したサービスは**できる限り自分で使ってから書く**（最低でも無料体験は試す）
- 比較・レビューでは**良い点も悪い点も両方書く**
- 公式サイトへの誘導は**読者が最終判断できる情報を揃えた上で**行う

### やらないこと

- ❌ 単価が高いというだけの理由で推す
- ❌ 使ったこともないサービスを「おすすめ」と書く
- ❌ 他社を不当に貶めて自社推しサービスを持ち上げる
- ❌ 根拠のない「絶対」「確実」「必ず稼げる」等の表現
- ❌ 法律違反・規約違反の手法を紹介する
- ❌ 誇大広告（景品表示法・特商法違反）

## 5. 品質基準（公開してよい記事の最低ライン）

以下を**すべて満たさない記事は公開しない**。

- [ ] メインキーワードで検索したとき、読者が求める答えが記事内にある
- [ ] 公式サイトのコピペではなく、独自の視点や情報が1つ以上ある
- [ ] 紹介するサービスの弱点・向いていない人が明記されている
- [ ] 断言している箇所には根拠（数字・出典）がある
- [ ] 誤字脱字がない（声に出して読んでチェック）
- [ ] スマホで実際に表示を確認した
- [ ] PR表記がファーストビューに出ている

詳細なチェックリストは `article-writing-guide.md` の「13. 公開前チェックリスト」を参照。

## 6. 書かないテーマ・紹介しないサービス

### 扱わないテーマ
- 投機性の高い金融商品（FX、仮想通貨の初心者向け勧誘など）
- 医療・健康に関する断定的なアドバイス
- ネットワークビジネス・MLM
- 法令・倫理に反する副業・稼ぎ方

### 紹介しないサービス
- 返金保証やキャンセルポリシーが極端に不利なもの
- SNSや口コミで明らかに被害報告が多いもの
- 運営会社の実態が不明瞭なもの
- 料金が極端に不透明なもの（事前に総額がわからない）

**迷ったら「このサービスを親にすすめられるか？」で判断する。**

## 7. ブランドボイス（サイトの語り口）

### このサイトは「信頼できる先輩」である

偉そうな専門家でも、友達のノリでもなく、
**「自分も同じ道を通ってきた、少し先を行く先輩」** として語りかけます。

### トーンの指針

| やる | やらない |
|---|---|
| 「〜です・ます」調で丁寧に | タメ口、馴れ馴れしい口調 |
| 具体的な例で説明する | 抽象的なポエム |
| 根拠とセットで断言する | 根拠なき煽り |
| 読者の不安に寄り添う | 不安を煽って売る |
| 専門用語は解説を添える | 業界用語の連発 |
| 「私は」ではなく「当サイトでは」 | 過度な自己アピール |

### 使いたい言葉・使いたくない言葉

**使いたい言葉:**
- 「〜が向いています」「〜の方におすすめです」
- 「デメリットは〜」「注意点は〜」
- 「実際に使ってみると〜」
- 「公式サイトによると〜」

**使いたくない言葉:**
- 「絶対」「必ず」「誰でも」「確実に」
- 「稼げる」「成功する」（根拠なしに）
- 「最高」「最強」「究極」（誇大表現）
- 「激安」「超お得」（胡散臭くなる）

## 8. 差別化の方針

競合が強いジャンルでも勝つために、このサイトは以下の軸で差別化します。

### 軸1: 「比較」の質にこだわる
他サイトが「7社横並び」で紹介するだけなのに対し、
**「こういう人にはA、こういう人にはB」と読者のタイプ別に推す**。

### 軸2: 補助金 × サービス比較
単なるサービス比較ではなく、**教育訓練給付金・リスキリング補助金との組み合わせ**で、
実質負担額まで見せる。これは多くの競合が手薄な領域。

### 軸3: 年代別 × 分野別のマトリクス
「40代 × プログラミング」「50代 × 英語」など、
**ペルソナを絞った記事**を作り、ビッグキーワードでの正面対決を避ける。

### 軸4: 実体験ファースト
「公式サイトの情報をまとめました」ではなく、
**「実際に使ってどうだったか」を主軸**にする。
E-E-A-T（特にExperience＝経験）で差をつける。

## 9. 迷ったときの判断基準

記事を書いていて迷ったら、以下の順番で自問してください。

1. **これは読者の役に立つか？** → Noなら書かない
2. **根拠はあるか？** → なければ調べるか、表現を弱める
3. **自分が読者だったら、この情報で行動できるか？** → Noなら具体性を足す
4. **この記事を身近な人に見せられるか？** → 恥ずかしいなら書き直す
5. **3年後もこの内容で大丈夫か？** → 古くなる情報は更新前提で書く

- `article-writing-guide.md` のチェックリストを通す

- このドキュメントを更新する（方針が記事より先）
