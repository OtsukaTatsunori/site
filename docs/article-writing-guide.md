# 記事制作ガイド — Part 1: 基本ルールと構成テンプレート

このガイドは「大人の学びなおし比較」の記事を書くときに守るべきルールをまとめたものです。
記事を書く前に必ず読み、書いている途中も見返してください。

---

## 1. 記事制作の5つの原則

### 原則1: 1記事1キーワード
- 1つの記事で狙うメインキーワードは**必ず1つ**
- 「大人 英語 学び直し」と「大人 プログラミング」を同じ記事で狙わない
- 複数狙うと、検索エンジンにテーマが伝わらず上位表示されない

### 原則2: 検索意図から逆算する
記事を書く前に必ず確認:
1. **誰が** そのキーワードで検索するか（ペルソナ）
2. **何を** 知りたくて検索するか（Informational / Navigational / Transactional）
3. **検索結果上位10位** を実際に見て、どんな情報が求められているか確認

**例:** 「大人 英語 学び直し」で検索する人
- 40代〜50代の社会人
- 英語をゼロからやり直したい
- どのサービスが自分に合うか知りたい（比較・ランキング型の記事が上位）

### 原則3: 結論ファースト
- 冒頭で「この記事の結論」を書く
- 読者は3秒で離脱判断する
- スクロールしなくても概要がわかる構造にする

### 原則4: 一次情報を入れる
- 公式サイトの情報をコピペしただけの記事は評価されない
- 実際に使った感想、独自の比較軸、オリジナル画像を入れる
- E-E-A-T（経験・専門性・権威性・信頼性）を意識

### 原則5: 読者の行動を促す
- 記事の目的は読者に何かしらの「行動」を取らせること
- アフィリエイトリンクをクリックしてもらう
- 別の記事を読んでもらう
- 記事の最後に必ず「次のアクション」を配置

## 2. タイトルの付け方

### ルール
- **文字数**: 32文字前後（Googleの表示上限）
- **メインKWは左寄せ**: 「大人 英語 学び直し おすすめ【2026年】」✅
  - 「【2026年】おすすめの大人英語学び直し」❌（KWが右寄り）
- **数字を入れる**: 「7選」「5つの理由」「3ステップ」など
- **ベネフィットを明示**: 「最短で」「初心者でも」「失敗しない」
- **年号を入れる**: 「2026年」「最新版」（情報の新しさをアピール）

### タイトルのテンプレート

**比較・ランキング記事:**
```
【2026年最新】{キーワード}おすすめ{N}選｜{特徴や対象}を徹底比較
例: 【2026年最新】大人の英語学び直しおすすめ7選｜初心者向けを徹底比較
```

**レビュー記事:**
```
{サービス名}の評判・口コミは？{特徴}を徹底レビュー【{年}】
例: スタディサプリENGLISHの評判・口コミは？大人の学び直しに使えるか徹底レビュー【2026】
```

**情報・How-to記事:**
```
{キーワード}｜{誰が}{何を}するための{N}ステップ
例: 学び直しは何から始める？社会人が失敗しない5つのステップ
```

**悩み解決記事:**
```
{悩み}で困っている人へ｜{解決策}を{専門性}が解説
例: 40代からの学び直しで迷っている人へ｜続けやすいジャンル5選を解説
```

## 3. メタディスクリプションの書き方

### ルール
- **文字数**: 120文字前後（スマホで完全表示される長さ）
- **メインKWを前半に含める**
- **記事を読むメリットを明示**
- **行動を促すフレーズ**を入れる（「〜を解説」「〜がわかる」）

### テンプレート

```
{メインKW}について解説します。
{記事の要点1}、{記事の要点2}、{記事の要点3}を紹介。
{この記事を読むメリット}がわかります。
```

### 例

```
大人の英語学び直しにおすすめのサービス7選を徹底比較。オンライン英会話、英語コーチング、アプリ型学習の特徴と料金、向いている人を解説。初心者でも続けられるサービスの選び方がわかります。
```

## 4. パーマリンク（スラッグ）の設定ルール

### ルール
- **半角英数字のみ**（日本語URLは避ける）
- **短く、内容を表す単語**
- **単語はハイフン（-）で区切る**
- **アンダースコア（_）は使わない**

### 例

| 記事タイトル | スラッグ |
|---|---|
| 大人の英語学び直しおすすめ7選 | `adult-english-learning` |
| スタディサプリENGLISH レビュー | `studysapuri-english-review` |
| リスキリング補助金 2026 | `reskilling-subsidy-2026` |
| 50代の学び直しガイド | `50s-learning-guide` |
| 教育訓練給付金おすすめ講座 | `kyufukin-courses` |

**注意:** 一度公開したらスラッグを変更しない（URLが変わりSEO評価がリセットされる）

## 6. 記事の文字数目安

| 記事タイプ | 目安文字数 |
|---|---|
| 比較・ランキング記事（メイン収益記事） | 8,000〜15,000字 |
| レビュー記事 | 5,000〜10,000字 |
| 情報・How-to記事 | 3,000〜6,000字 |
| 短いまとめ記事 | 2,000〜4,000字 |

**重要:** 文字数は「SEOのため」ではなく「検索意図を満たすため」に必要な情報量から決める。
競合上位10サイトの平均文字数を参考に、少し上回る文字数を目指す。

# Part 2: ライティングとSEO対策

## 7. ライティングの基本ルール

### 文体
- **です・ます調で統一**（だ・である調は避ける）
- 一人称は「私」または「当サイト」
- 読者への呼びかけは「あなた」または「〇〇の方」

### 一文のルール
- **一文は60文字以内**を目安にする
- 主語と述語を近くに置く
- 一文に複数の情報を詰め込まない

**悪い例:**
> 大人の学び直しにはたくさんの選択肢があるので自分に合ったサービスを見つけるためには時間をかけて比較検討することが大切で、料金や学習内容、サポート体制などを総合的に判断する必要があります。（100文字超、情報が多すぎ）

**良い例:**
> 大人の学び直しには、たくさんの選択肢があります。
> 自分に合うサービスを見つけるには、時間をかけて比較することが大切です。
> 料金、学習内容、サポート体制を総合的に判断しましょう。

### PREP法で書く
読者が最後まで読まなくても要点が伝わる構造。

- **P**oint（結論）
- **R**eason（理由）
- **E**xample（具体例）
- **P**oint（もう一度結論）

**例:**
> **Point**: 大人の学び直しには、オンライン英会話が最もおすすめです。
> **Reason**: 理由は、社会人でもスキマ時間で続けられるからです。
> **Example**: 例えばDMM英会話なら、24時間いつでも25分のレッスンが受けられます。朝5時に1レッスン、通勤前に英語を使う習慣が作れます。
> **Point**: このように、継続しやすさの観点から、大人の英語学び直しにはオンライン英会話が最適です。

### 読みやすさのコツ

#### 1. 漢字・ひらがな・カタカナのバランス
- **漢字:ひらがな = 3:7** が理想
- 難しい漢字はひらがなに開く
  - ❌「出来る」→ ⭕「できる」
  - ❌「無駄」→ ⭕「ムダ」
  - ❌「事」→ ⭕「こと」

#### 2. 適度な改行
- 2〜3文で1つの段落
- 段落間に空行を入れる
- スマホで読みやすくなる

#### 3. 箇条書きを活用
3つ以上の項目を並べるときは必ず箇条書きにする。

**悪い例:**
> DMM英会話のメリットは、料金が安いこと、24時間レッスンが受けられること、講師数が多いこと、教材が豊富なことです。

**良い例:**
> DMM英会話のメリットは以下の4つです。
> - 料金が業界最安クラス
> - 24時間いつでもレッスン可能
> - 講師数が業界最多クラス
> - 教材が1万以上と豊富

#### 4. 太字・マーカーの活用
- **重要な箇所は太字**にする
- マーカー（黄色ライン）は1段落に1箇所まで
- 多用すると逆に目立たなくなる

## 8. 信頼性を高める書き方（E-E-A-T対策）

Googleは以下の4つを重視します：

- **E**xperience（経験）
- **E**xpertise（専門性）
- **A**uthoritativeness（権威性）
- **T**rustworthiness（信頼性）

### 経験（Experience）を示す
- 「実際に使ってみた」体験談を入れる
- スクリーンショットを添付する
- 具体的な数字（何日使ったか、何回レッスンを受けたか）を書く

### 専門性（Expertise）を示す
- カテゴリに関連するプロフィール情報を記事冒頭や末尾に入れる
- 統計データや公式情報を根拠として引用する
- 業界用語を正しく使う

### 権威性（Authoritativeness）を示す
- 公式サイトへの適切なリンクを設置
- 信頼できる情報源（厚生労働省、経産省等）を引用

### 信頼性（Trustworthiness）を示す
- **出典を明記する**
  - 「〇〇調査（2025年）によると」
  - 「厚生労働省のデータでは」
- **更新日を記載する**（古い情報は定期的に更新）
- **根拠のない断言を避ける**
  - ❌「誰でも絶対に英語が話せるようになる」
  - ⭕「継続すれば英語力の向上が期待できる（※個人差あり）」

## 9. SEO対策の実践ルール

### 9-1. キーワードの配置

メインキーワードは以下の場所に必ず含める:

| 配置場所 | 重要度 |
|---|---|
| タイトル（左寄せ） | ★★★ |
| メタディスクリプション | ★★★ |
| H1（記事タイトルと同じ） | ★★★ |
| 冒頭100字以内 | ★★★ |
| H2見出しの複数箇所 | ★★ |
| 本文中に自然な形で | ★★ |
| 画像のalt属性 | ★ |
| まとめ部分 | ★ |

**注意:** キーワードの不自然な詰め込み（キーワードスタッフィング）は逆効果。読みやすさ最優先。

### 9-2. 共起語・関連語の活用

メインキーワードと一緒によく使われる単語を本文に自然に含める。
検索エンジンが「このテーマを網羅的に扱っている記事」と判断してくれる。

**例:** 「大人 英語 学び直し」の共起語
- オンライン英会話
- 初心者
- 発音
- リスニング
- 社会人
- 独学
- 無料
- アプリ
- 教材
- おすすめ

### 9-3. 内部リンクの張り方

**基本ルール:**
- 1記事あたり3〜5個の内部リンクを入れる
- アンカーテキスト（リンクのテキスト）にキーワードを含める
- 関連性の高い記事にリンクする

**悪い例:**
> 詳しくは[こちら](link)

**良い例:**
> [大人の英語学び直しにおすすめのサービス7選](link)を比較した記事も参考にしてください。

**内部リンク構造:**
```
情報記事（入口）
  ↓ リンク
カテゴリのまとめ記事
  ↓ リンク
比較・ランキング記事
  ↓ リンク
個別サービスのレビュー記事
  ↓ CTA
アフィリエイトリンク（成約）
```

### 9-4. 見出し（H2/H3）のルール

- **H1は1記事に1つだけ**（記事タイトル）
- **H2の数は5〜10個**を目安
- H2にはできるだけメインKW or 関連KWを含める
- **H3はH2の下に配置**し、論理的な階層構造を守る

**悪い例（階層がバラバラ）:**
```
H2: はじめに
  H4: 〇〇とは  ← 飛ばしすぎ
H2: 本論
  H3: ポイント1
    H2: ポイント2  ← 降格している
```

**良い例:**
```
H2: はじめに
H2: 〇〇とは
  H3: 定義
  H3: 歴史
H2: 本論
  H3: ポイント1
  H3: ポイント2
H2: まとめ
```

### 9-5. 画像のSEO対策

- **alt属性を必ず設定**する
  - 画像の内容を簡潔に説明
  - 可能ならメインKWを含める
- **ファイル名も英数字**で意味のある名前に
  - ❌ `IMG_0123.jpg`
  - ⭕ `english-learning-apps.jpg`
- **ファイルサイズは200KB以下**に圧縮
  - TinyPNG等で圧縮してからアップロード
  - EWWW Image Optimizerプラグインで自動圧縮も可

### 9-6. 更新日の管理

- 記事公開後も定期的に情報を更新する
- 特に料金・サービス内容は3ヶ月に1度チェック
- 更新したら「更新日」が表示されるように（Cocoon設定で有効化済み）
- 大きな変更があればタイトルに「【2026年最新】」等を追記

# Part 3: Cocoon装飾・アフィリエイトリンク・チェックリスト

## 10. Cocoon装飾の使い分け

Cocoonには多彩な装飾機能があります。使いすぎるとごちゃごちゃするので、目的に応じて使い分けましょう。

### 10-1. ボックス

**情報ボックス（青）**: 補足情報や豆知識
```
💡 スタディサプリは月額で解約も簡単にできます。
```

**注意ボックス（黄）**: 気をつけてほしい注意事項
```
⚠️ 無料体験後は自動的に有料会員に切り替わるので注意。
```

**危険ボックス（赤）**: 重大なリスク
```
🚫 この方法は法律違反にあたる可能性があります。
```

**OKボックス（緑）**: メリット、推奨事項
```
✅ この機能は初心者に特におすすめです。
```

**Cocoonブロックの「ボックス」から選択可能**

### 10-2. ボタン（アフィリエイト用）

**用途:** アフィリエイトリンクの最重要CTA

**色の使い分け:**
- **オレンジ/赤系**: 「今すぐ申し込む」系の強いCTA
- **青系**: 「詳細を見る」系の穏やかなCTA
- **緑系**: 「無料で試す」系の安心感のあるCTA

**ボタンテキストの例:**
- 「無料で体験レッスンを受ける」
- 「公式サイトで詳細を確認する」
- 「今すぐ申し込む（30秒で完了）」
- 「無料体験はこちら」

**Cocoon独自機能:** Cocoon設定 → アフィリエイトタグでボタンを登録しておくと、ショートコードで呼び出せる。URL変更時に一括更新可能。

### 10-3. 比較表

比較記事では必須のCocoonブロック。

**使い方のコツ:**
- **縦軸**: サービス名
- **横軸**: 比較項目（料金、期間、特徴、サポート等）
- **4〜7項目**に絞る（多すぎると見づらい）
- **◎○△×** で直感的に分かるようにする

**例:**

| サービス | 月額料金 | レッスン時間 | 講師数 | 無料体験 |
|---|---|---|---|---|
| DMM英会話 | 6,980円 | 25分 | 10,000人 | 2回 |
| レアジョブ | 4,620円 | 25分 | 6,000人 | 2回 |
| ネイティブキャンプ | 7,480円 | 25分 | 12,000人 | 7日間 |

### 10-4. 吹き出し

**用途:** 会話風に読者に語りかけることで、テンポよく読ませる

**使いどころ:**
- 導入部で読者の悩みを代弁
- Q&Aセクション
- 体験談で感情を表現

**例:**
```
[吹き出し左]「英語を学び直したいけど、何から始めればいいかわからない...」
[吹き出し右]「オンライン英会話なら、初心者でも続けやすいですよ！」
```

**注意:** 多用しすぎない。1記事3〜5回まで。

### 10-5. ランキング機能

比較・ランキング記事で使う。

**Cocoon設定 → ランキング** で1〜10位まで自動でメダル付きの順位表示ができる。

### 10-6. アフィリエイトタグ管理

**Cocoon管理画面 → アフィリエイトタグ** から頻出するアフィリエイトリンクを登録。

**メリット:**
- ショートコードで記事に挿入: `[affi id=1]`
- URL変更時に一括更新できる
- 表示回数・クリック数の計測が可能

**登録しておくべきもの:**
- 各ASPのボタンリンク（メインCTA用）
- 各ASPのテキストリンク

## 11. アフィリエイトリンクの配置ルール

### 11-1. 配置場所

**基本3箇所に配置する:**

1. **記事冒頭の結論付近**: 読者が「買う気」で検索してきた場合、すぐクリックできる場所に
2. **本文中の適切な箇所**: サービス紹介の直後、メリット説明の後
3. **まとめの直前**: 最後に迷っている読者の背中を押す

**悪い例:** 記事の最後に1箇所だけ
**良い例:** 導入・本文・まとめの3箇所に自然に配置

### 11-2. ボタン vs テキストリンク

| タイプ | 使いどころ |
|---|---|
| **大きなボタン（目立つ）** | 記事の最後のCTA、重要な申込み導線 |
| **小さなボタン** | 各サービス紹介の直後 |
| **テキストリンク** | 本文中の自然な箇所 |

### 11-3. CTAの書き方

**3つの要素を入れる:**
1. **ベネフィット**（何が手に入るか）
2. **簡単さ**（かかる時間や手間の少なさ）
3. **行動**（何をすべきか）

**例:**
- ⭕「【30秒で登録】無料体験レッスンを受けてみる」
- ⭕「まずは7日間の無料体験から始める（クレカ不要）」
- ❌「こちら」（情報がなさすぎ）
- ❌「申し込み」（ベネフィットなし）

### 11-4. ステマ規制対応

**2023年10月施行の景品表示法改正で必須:**

- 記事冒頭（ファーストビュー）に「当サイトはアフィリエイト広告を利用しています」の表示
- Cocoon設定 → 広告 → PR表記で自動挿入済み（初期設定ガイドで設定済み）
- アフィリエイトリンクだけの記事には特にしっかり表示

**やってはいけない:**
- ステマ（広告と明示せず広告する）
- 虚偽の体験談
- 誇大表現（「絶対に稼げる」等）

## 12. 画像のルール

### 12-1. アイキャッチ画像

- **サイズ**: 1200 x 630px（OGP兼用）
- **形式**: JPEG（写真系）または PNG（イラスト系）
- **ファイルサイズ**: 200KB以下
- **文字入れ**: 記事のタイトルやキーワードを大きく入れると訴求力UP

### 12-2. 記事内画像

- **幅**: 800px前後（スマホでも見やすい）
- **本文1,000字ごとに1枚**を目安に配置
- **スクリーンショット**は積極的に活用（E-E-A-T対策）

### 12-3. おすすめ無料画像サイト

| サイト | 特徴 |
|---|---|
| [O-DAN](https://o-dan.net/) | 複数の海外サイトを一括検索 |
| [Unsplash](https://unsplash.com/) | 高品質な写真 |
| [Pexels](https://www.pexels.com/) | 写真・動画 |
| [ぱくたそ](https://www.pakutaso.com/) | 日本人モデルの写真 |
| [いらすとや](https://www.irasutoya.com/) | イラスト |
| [Canva](https://www.canva.com/) | アイキャッチ画像の作成 |

### 12-4. alt属性の書き方

- 画像の内容を簡潔に説明
- メインKWを自然に含める（詰め込まない）
- 装飾目的の画像は空でOK（alt=""）

**例:**
- ⭕ `alt="DMM英会話の無料体験レッスン画面"`
- ⭕ `alt="大人の英語学び直しにおすすめの教材"`
- ❌ `alt="IMG_0123"`

## 14. よくある失敗と対策

### 失敗1: 検索意図とずれた記事を書く
**対策:** 執筆前に必ず実際のGoogle検索上位10記事を確認する

### 失敗2: タイトル・見出しにKWがない
**対策:** 執筆後に「メインKW、関連KWが含まれているか」を指差し確認

### 失敗3: アフィリエイトリンクの置き方が不自然
**対策:** 「自分が読者だったらクリックしたくなる場所か」を基準に配置

### 失敗4: 記事を公開して終わり
**対策:** Search Consoleで順位を確認し、3ヶ月後・6ヶ月後に加筆リライト

### 失敗5: 似た記事を量産してしまう
**対策:** サイト内で同じKWを狙う記事を2つ作らない（カニバリゼーション）。既存記事をリライトして強化する方針に。

## 15. 記事制作フロー（まとめ）

```
1. キーワード選定（docs/keyword-research.md から選ぶ）
   ↓
2. 検索意図の分析（Google上位10記事を確認）
   ↓
3. 記事構成作成（本ガイドのテンプレート使用）
   ↓
4. 執筆（PREP法・一文60字以内）
   ↓
5. Cocoon装飾で仕上げ（ボックス・比較表・ボタン）
   ↓
6. アフィリエイトリンク配置（3箇所以上）
   ↓
7. 画像の挿入・alt設定
   ↓
8. チェックリストで品質確認
   ↓
9. 公開
   ↓
10. 3ヶ月・6ヶ月後にリライト
```

このフローで記事を作れば、SEOに強く、読者の行動につながる記事が書けます。
