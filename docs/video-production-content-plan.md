# 動画制作カテゴリ コンテンツプラン

動画制作カテゴリで作成する記事の全体マップです。
新しい記事を選定するときは、まずこのドキュメントに戻ってきてカニバリとクラスター設計を確認してください。

---

## 1. 全体構造：ピラー × クラスター型

```
                    【ピラー記事】
                動画編集 未経験（既存）
                        │
   ┌────────────┬────────────┬────────────┬────────────┐
   │            │            │            │            │
ソフト系     デバイス系     用途系       深掘り系      工程系
   │            │            │            │            │
・無料ソフト  ・PC選び      ・YouTube編集 ・案件の取り方 ・テロップ
・CapCut     ・Mac vs Win  ・ショート動画 ・ポートフォリオ・サムネ
  vs Premiere・iPadだけで  ・結婚式      ・フリーランス ・カラー
・DaVinci     ・ノートPC    ・Vlog                     ・BGM
  使い方                   ・切り抜き
```

- **ピラー記事（1本）**：カテゴリ全体の入口。包括的に扱う
- **クラスター記事（複数本）**：ピラーから派生し、特定テーマを深掘り
- 各クラスター記事は**ピラーへの内部リンク**を必ず持たせる
- ピラーからも各クラスターへの内部リンクを追加する（`原則14, 15`）

## 2. カニバリ回避ルール

ピラー記事「動画編集 未経験」が包括的にカバー済みのため、以下のKWは**メインKWにしない**。

### 避けるべき単独KW

| KW | 理由 |
|---|---|
| 動画編集 | ビッグワード、個人サイトでは厳しい |
| 動画編集 始め方 | 既存の「4ステップロードマップ」と同義 |
| 動画編集 未経験 | 既存そのもの |
| 動画編集 独学 | 既存H2-3で扱い済み |
| 動画編集 副業 未経験 | 既存のテーマそのもの |
| 動画編集 スクール 未経験 | 既存H2-5で比較済み |
| Premiere Pro（単独） | 商標、公式に勝てない |
| Final Cut Pro（単独） | Apple商標 |

### 「深掘り」なら可（差別化必須）

- 動画編集 案件 取り方 → 既存STEP4の深掘り
- 動画編集 ポートフォリオ 作り方 → 既存STEP3の深掘り
- 動画編集 スクール おすすめ 比較 → 比較軸を増やした専用比較記事

これらは **既存記事よりも3〜4倍詳しく** 書くことで差別化する。

## 4. 不採用にしたKW（理由記録）

| KW | 不採用理由 |
|---|---|
| 動画編集（単独） | ビッグワード。上位は大手メディアのみ |
| 動画制作（単独） | 同上。BtoBニーズにも被りアフィ相性× |
| 映像制作（単独） | 同上 |
| Premiere Pro 使い方 | Adobe公式＋有名Youtuberが上位独占 |
| Final Cut Pro 使い方 | Apple商標、個人サイトでは勝てない |
| 動画編集 副業 稼げる | 誇大表現抵触リスク、ASPからNG出る可能性 |
| 切り抜き動画 編集 | 著作権グレー、推奨しにくい |
| AI動画 編集 | トレンドだが技術変化が早く記事寿命が短い |

## 6. 運用ルール

1. **新記事を書く前にこのドキュメントを開く**
2. 選定したKWが「避けるべき単独KW」に該当しないか確認
3. 既存記事との差別化ポイントを明確にしてから着手
4. 公開後はステータスを `🔜 次` → `✅ 済` に更新
5. 内部リンクマップも随時更新（ピラー → クラスター、クラスター → ピラー）
