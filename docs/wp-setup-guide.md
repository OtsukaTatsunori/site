# WordPress 初期設定 手順書

この手順書に沿って、WordPress管理画面で設定してください。
上から順番に進めれば完了します。

---

## STEP 1: 基本設定（5分）

### 設定 → 一般
1. サイトのタイトル: 「大人の学びなおし比較」（確認のみ）
2. キャッチフレーズ: 「社会人・大人向け学習サービスを徹底比較」
3. WordPress アドレス / サイトアドレス: `https://` になっていること確認
4. **変更を保存**

### 設定 → パーマリンク
1. 「投稿名」を選択（/%postname%/）
2. **変更を保存**
   ※ 一度設定したら二度と変更しないこと

### 設定 → ディスカッション
1. 「新しい投稿へのコメントを許可」→ **チェックを外す**
2. 「新しい記事に対し他のブログからの通知を受け付ける」→ **チェックを外す**
3. **変更を保存**

### 設定 → 表示設定
1. 「検索エンジンがサイトをインデックスしないようにする」→ **チェックが入っていない**ことを確認
2. **変更を保存**

---

## STEP 2: プロフィール設定（3分）

### ユーザー → プロフィール
1. ニックネーム: ログインIDとは**別の名前**を入力（セキュリティ対策）
2. ブログ上の表示名: ↑で設定したニックネームを選択
3. プロフィール情報: 以下のような自己紹介文を入力

```
社会人の学び直し・リスキリングに関する情報を発信しています。
自身も働きながらオンライン学習サービスを活用して
スキルアップに取り組んでいます。
実体験をもとに、大人の学び直しに役立つ情報をお届けします。
```

4. **プロフィールを更新**

---

## STEP 3: 不要コンテンツ削除（2分）

### 投稿 → 投稿一覧
1. 「Hello world!」→ ゴミ箱へ移動

### 固定ページ → 固定ページ一覧
1. 「サンプルページ」→ ゴミ箱へ移動

### プラグイン → インストール済みプラグイン
1. 「Hello Dolly」→ 削除
2. 「Akismet Anti-Spam」→ 削除（コメント無効化したため不要）

### 外観 → テーマ
1. Cocoon / Cocoon Child **以外**のテーマ（Twenty Twenty系）→ 削除

---

## STEP 4: Cocoon設定（10分）

管理画面 → **Cocoon設定** を開く

### スキン
1. 好みのスキンを選択（プレビューで確認可能）
2. おすすめ: シンプル系（JEEO Flavor, Season, シンプルホワイト等）
3. **変更をまとめて保存**

### 全体
1. キーカラー: サイトのメインカラーを設定（例: #2196F3 青系、#4CAF50 緑系）
2. フォント: 游ゴシック（デフォルトでOK）
3. フォントサイズ: 16px
4. サイドバーの位置: 右（デフォルト）
5. **変更をまとめて保存**

### SEO
1. フロントページタイトル: 「大人の学びなおし比較｜社会人向け学習サービスを徹底比較」
2. フロントページのメタディスクリプション:

```
大人・社会人向けの学び直しサービスを徹底比較。プログラミング、英語、資格取得、オンライン学習など、目的別・年代別におすすめのサービスを紹介。リスキリング補助金・教育訓練給付金の活用方法も解説します。
```

3. **タグページ** → 「noindex」にチェック
4. canonicalタグ → 有効であること確認
5. **変更をまとめて保存**

### 高速化
1. ブラウザキャッシュの有効化 → **チェック**
2. HTMLを縮小化する → **チェック**
3. CSSを縮小化する → **チェック**
4. JavaScriptを縮小化する → **チェック**
5. Lazy Loadを有効にする → **チェック**
6. **変更をまとめて保存**

### 広告（ステマ規制対応 — 必須）
1. PR表記設定を開く
2. 自動挿入ページ: 「全ての投稿ページ」「全ての固定ページ」にチェック
3. 自動挿入エリア: 「本文の上」
4. 表記テキスト: 「当サイトはアフィリエイト広告を利用しています」
5. **変更をまとめて保存**

### 本文
1. 「横幅の広いテーブルは横スクロール」→ **チェック**（比較表で重要）
2. **変更をまとめて保存**

### 目次
1. 「目次を表示する」→ **チェック**
2. 表示条件: 見出し数 2
3. 目次表示の深さ: H3まで
4. **変更をまとめて保存**

### 投稿
1. パンくずリストの配置: 「メインカラムトップ」
2. 「投稿関連情報」→ 投稿日・更新日: 両方表示
3. 「投稿者名の表示」→ 表示する
4. **変更をまとめて保存**

### OGP
1. OGP設定を有効にする → **チェック**
2. Twitterカードタイプ: 「大きな画像のサマリー」
3. ホームイメージ: OGP画像をアップロード（1200x630px推奨）
   ※ 後でCanva等で作ってもOK
4. **変更をまとめて保存**

### アクセス集計
1. 「アクセス集計の有効化」→ **チェックを外す**（GA4で代替、サーバー負荷軽減）
2. **変更をまとめて保存**

---

## STEP 5: カテゴリー設定（3分）

### 投稿 → カテゴリー

まず「未分類」を変更:
1. 「未分類」→ 編集 → 名前「お知らせ」、スラッグ「news」に変更

次に以下のカテゴリーを新規追加:

| 名前 | スラッグ |
|---|---|
| 英語・語学 | english |
| プログラミング・IT | programming |
| 資格・検定 | qualification |
| オンライン学習 | online-learning |
| 教科別やり直し | subject |
| 補助金・制度 | subsidy |
| 年代別ガイド | age-guide |

---

## STEP 6: 固定ページ作成（10分）

以下の4ページを作成します。
テンプレートは `docs/pages/` フォルダに用意してあるので、コピペしてください。

| ページ名 | スラッグ | テンプレート |
|---|---|---|
| プライバシーポリシー | privacy-policy | docs/pages/privacy-policy.txt |
| 免責事項 | disclaimer | docs/pages/disclaimer.txt |
| お問い合わせ | contact | docs/pages/contact.txt |
| プロフィール | profile | docs/pages/profile.txt |

固定ページ作成手順（共通）:
1. 固定ページ → 新規追加
2. タイトルを入力
3. 本文にテンプレートの内容をコピペ
4. 右パネル → パーマリンク → スラッグを設定
5. 右パネル → ページ属性 → テンプレート「1カラム（広い）」
6. 公開

---

## STEP 7: メニュー設定（3分）

### 外観 → メニュー

**グローバルメニュー（ヘッダー）を作成:**
1. メニュー名: 「グローバルメニュー」
2. カテゴリーから追加: 英語・語学、プログラミング・IT、資格・検定、オンライン学習、補助金・制度
3. 表示位置: 「ヘッダーメニュー」にチェック
4. **メニューを保存**

**フッターメニューを作成:**
1. 「新しいメニューを作成」
2. メニュー名: 「フッターメニュー」
3. 固定ページから追加: プライバシーポリシー、免責事項、お問い合わせ、プロフィール
4. 表示位置: 「フッターメニュー」にチェック
5. **メニューを保存**

---

## STEP 8: ウィジェット設定（2分）

### 外観 → ウィジェット

**サイドバーから不要なウィジェットを削除:**
- メタ情報 → 削除
- 最近のコメント → 削除

**サイドバーに追加（上から順に）:**
1. プロフィール（Cocoon標準）
2. 検索
3. カテゴリー
4. 人気記事（Cocoon標準）

---

## STEP 9: プラグイン追加（5分）

### プラグイン → 新規追加

1. 「Contact Form 7」を検索 → インストール → 有効化
2. EWWW Image Optimizer を検索 → インストール → 有効化

Contact Form 7 設定:
1. お問い合わせ → コンタクトフォーム → 「コンタクトフォーム1」を開く
2. ショートコードをコピー
3. 固定ページ「お問い合わせ」の本文に貼り付け → 更新

---

## 完了チェック

すべて終わったら「サイトを表示」で以下を確認:
- [ ] スキンが適用されている
- [ ] ヘッダーメニューにカテゴリが表示されている
- [ ] フッターに固定ページリンクがある
- [ ] サイドバーにプロフィールが表示されている
- [ ] 「Hello world!」記事が消えている
