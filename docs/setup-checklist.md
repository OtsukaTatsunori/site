# サイト初期設定チェックリスト

優先度: **必須** / 推奨 / 後でOK

## Phase 1 — サイト公開前（最優先）

### WordPress基本設定

- [ ] **必須** 設定 → 一般: サイトタイトル＆キャッチフレーズ確認
- [ ] **必須** 設定 → 一般: アドレスが https:// であること確認
- [ ] **必須** 設定 → パーマリンク: 「投稿名」（/%postname%/）に変更
- [ ] **必須** 設定 → ディスカッション: コメントを無効化（スパム対策）
- [ ] **必須** 設定 → ディスカッション: ピンバック・トラックバックをオフ
- [ ] **必須** 設定 → 表示設定: 「検索エンジンにインデックスさせない」に**チェックが入っていない**こと確認
- [ ] **必須** ユーザー → プロフィール: ニックネームをログインIDと別の名前に変更
- [ ] **必須** ユーザー → プロフィール: ブログ上の表示名をニックネームに変更
- [ ] **必須** ユーザー → プロフィール: プロフィール情報を入力（E-E-A-T対策）

### 不要コンテンツ・プラグインの削除

- [ ] **必須** 「Hello world!」投稿を削除
- [ ] **必須** サンプルページ（固定ページ）を削除
- [ ] **必須** 「Hello Dolly」プラグインを削除
- [ ] 推奨 「Akismet」プラグインを削除（コメント無効化するため不要）
- [ ] 推奨 未使用テーマ（Twenty Twenty系など）を削除

### Cocoon基本設定（Cocoon設定）

- [ ] **必須** スキン: シンプルで清潔感あるスキンを選択
- [ ] **必須** 全体: キーカラーを設定
- [ ] 推奨 全体: フォント — 游ゴシック or Noto Sans JP、サイズ16px
- [ ] 推奨 全体: サイドバー — 右サイドバー（デフォルト）
- [ ] **必須** 全体: レスポンシブデザインが有効であること確認

### Cocoon SEO設定

- [ ] **必須** SEO: トップページ用メタディスクリプション（120文字以内）
- [ ] **必須** SEO: canonicalタグの追加が有効であること確認
- [ ] **必須** SEO: タグページを noindex に設定
- [ ] 推奨 SEO: カテゴリページは最初 noindex → 記事充実後に index へ

### Cocoon高速化設定

- [ ] **必須** 高速化: ブラウザキャッシュ有効化
- [ ] **必須** 高速化: HTML縮小化
- [ ] **必須** 高速化: CSS縮小化
- [ ] **必須** 高速化: JavaScript縮小化
- [ ] **必須** 高速化: Lazy Load有効化
- [ ] 推奨 Cocoonアクセス集計を無効化（GA4で代替、サーバー負荷軽減）

### ステマ規制対応（景品表示法 2023年10月施行）

- [ ] **必須** Cocoon設定 → 広告 → PR表記: 自動挿入ページ「全ての投稿・固定ページ」
- [ ] **必須** PR表記の挿入エリア: 「本文の上」（ファーストビューに表示）
- [ ] **必須** PR表記テキスト: 「当サイトはアフィリエイト広告を利用しています」

### 固定ページ作成

- [ ] **必須** プライバシーポリシー（スラッグ: privacy-policy）
  - 個人情報取り扱い、Cookie、GA4利用、広告配信、アフィリエイト参加、免責事項
- [ ] **必須** 免責事項（スラッグ: disclaimer）※プライバシーポリシーと統合可
  - 情報正確性の非保証、外部リンク免責、アフィリエイト広告利用の明示
- [ ] **必須** お問い合わせ（スラッグ: contact）
  - Contact Form 7 または WPForms を使用
  - Google reCAPTCHA v3 でスパム対策
- [ ] **必須** プロフィール/運営者情報（スラッグ: profile）
  - 運営者名、経歴・専門性、サイト目的（E-E-A-T対策）
- [ ] 推奨 サイトマップ（スラッグ: sitemap）
  - Cocoonショートコード `[sitemap]` を挿入

### メニュー設定（外観 → メニュー）

- [ ] **必須** グローバルメニュー: 主要カテゴリへのリンク
- [ ] **必須** フッターメニュー: プライバシーポリシー、免責事項、お問い合わせ、プロフィール

### ウィジェット設定

- [ ] **必須** サイドバーにプロフィールウィジェット設置
- [ ] 推奨 サイドバーに検索ウィジェット
- [ ] 推奨 サイドバーにカテゴリウィジェット
- [ ] **必須** 不要なデフォルトウィジェット削除（メタ情報、最近のコメント等）

### カテゴリー設定

- [ ] **必須** 「未分類」カテゴリーの名前とスラッグを変更
- [ ] **必須** カテゴリースラッグは半角英数字で設定

## 入れてはいけないプラグイン

- All in One SEO / Yoast SEO / RankMath（Cocoonと機能重複）
- Jetpack（重い、Cocoonと機能重複多い）
- 不要なキャッシュプラグイン（Cocoon自体にキャッシュ機能あり）

## Cocoon独自機能の活用

- **アフィリエイトタグ管理**: 管理画面「アフィリエイトタグ」で頻出リンクを一元登録 → ショートコードで記事に挿入。URL変更時に一括変更可能
- **Cocoonブロック**: ブロックエディターで比較表、ボタン、吹き出し等が簡単に作成可能
